> 因原域名 `pydaydayup.xyz` 过期且 Vercel CDN 中国大陆访问受阻，前端迁移至 Cloudflare Pages（免费，国内可访问）。

```
浏览器 → Cloudflare Pages (wxx-agent.pages.dev)
  ├── /*  → Flutter Web 静态文件（前端）
  └── /api/* → Pages Functions 代理 → Vercel Serverless（后端）
```

**前端地址**: `https://wxx-agent.pages.dev`
**后端地址**: `https://wxx-server-2apyus7gx-czldl.vercel.app`（仅 Functions 直连，不对外暴露）

### 方式二：手动部署

```bash
cd frontend

# 1. 构建
flutter build web --release

# 2. 准备部署目录（静态文件 + API 代理函数）
mkdir -p deploy
cp -r build/web/* deploy/
cp -r functions deploy/

# 3. 部署到 Cloudflare Pages
npx wrangler pages deploy deploy --project-name wxx-agent --branch main
```

## 项目文件说明

| 文件 | 作用 |
|---|---|
| `frontend/functions/api/[[route]].js` | Pages Functions — 将 `/api/*` 请求转发到 Vercel 后端 |
| `.github/workflows/deploy-frontend.yml` | GitHub Actions 自动部署 |
| `frontend/lib/config/api_config.dart` | API 地址配置（当前为空字符串，走同域代理） |

## API 代理原理

`frontend/functions/api/[[route]].js` 是一个 Cloudflare Pages Function，作用：

1. 前端发起请求 `/api/v1/auth/login`
2. Pages 匹配到 `functions/api/[[route]].js`
3. 转发到 `https://wxx-server-2apyus7gx-czldl.vercel.app/api/v1/auth/login`
4. 返回结果给前端（添加 CORS 头）

**优点**：
- 前后端同域，无 CORS 问题
- 利用 Cloudflare 中国边缘节点加速
- 无需单独维护 Workers 项目

## Vercel 后端仍保留

后端 Go 服务仍然部署在 Vercel Serverless（`wxx-server` 项目），域名 `api.pydaydayup.xyz` 已过期不可用，但 `.vercel.app` 原生域名仍可通过 Cloudflare Functions 代理访问。

如需重新部署后端：

```bash
cd server
go build ./...
# 从仓库根目录
npx vercel deploy --prod
```

> 后端 Vercel 项目：`wxx-server`（`czldl/wxx-server`），仓库根目录 `.vercel/repo.json` 指向此项目。
