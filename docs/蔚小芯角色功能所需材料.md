## 1. 通用功能（所有角色）

> **角色**：全员（含游客、学生、教师、辅导员、管理员等）  
> **前置**：隐私协议同意 + 账号登录

### 1.1 首次启动与登录

| 勾选 | 功能 | 优先级 | 所需材料 | 测试要点 |
|------|------|--------|----------|----------|
| ☐ | 隐私协议弹窗 | P0 | 隐私政策文档（法务审核版本） | 首次访问弹窗，同意→首页，不同意→停留 |
| ☐ | 密码登录 | P0 | 用户账号（种子账号或导入） | 正确密码→跳转首页；错误→提示；空字段→按钮不可用 |
| ☐ | 扫码登录 | P1 | 无（无需材料，使用标准 QR 码） | 二维码正常生成，轮询扫描状态 |
| ☐ | 退出登录 | P0 | 无 | 退出后回到游客模式，无法访问受限页面 |
| ☐ | 修改密码 | P0 | 无 | 旧密码 → 新密码 → 确认，成功后下次用新密码登录 |
| ☐ | 游客手机注册 | P1 | 短信验证码通道配置 | 输入称呼+手机号+验证码 → 注册成功转 guest 角色 |
