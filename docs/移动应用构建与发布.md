## 一、构建入口

`.github/workflows/build-mobile.yml`，仅 `workflow_dispatch` **手动触发**。

入口：GitHub → Actions → **Build Mobile Apps** → Run workflow。

两个输入（分别控制两个 Job 是否签名/发布）：

| 输入 | 取值 | 行为 |
|------|------|------|
| `ios_target` | `unsigned`（默认） | 未签名构建，产出 `.app.zip` 制品 |
| | `signed` | 签名构建（需 Apple 凭据），产出 `.ipa` |
| | `testflight` | 签名并上传 TestFlight（需 ASC API Key） |
| `harmonyos_target` | `unsigned`（默认） | 未签名 HAP 制品 |
| | `signed` | 签名 HAP（需华为 AGC 证书） |

## 二、产物与分发

| 平台 | 构建 Job | 产物 | 当前分发 |
|------|----------|------|----------|
| iOS | `build-ios`（macos-15） | `.app.zip`（unsigned）/ `.ipa` | GitHub Release `v0.0.27` ✅ |
| HarmonyOS | `build-harmonyos`（ubuntu） | `.hap` | GitHub Release `v0.0.27` ✅ |
| Android APK | `deploy-frontend.yml`（既有） | `weixiaoxin.apk`（固定名） | GitHub Release `vX.Y.Z` |

版本号统一读取 `frontend/pubspec.yaml` 的 `version:`（如 `0.0.27+27`），各端 App 版本与其保持一致：

- iOS：`Info.plist` 用 `$(FLUTTER_BUILD_NAME)` / `$(FLUTTER_BUILD_NUMBER)`，随 Flutter 构建自动同步。
- HarmonyOS：`frontend/harmonyos/AppScope/app.json5`（versionName/versionCode）与 `entry/src/main/module.json5`（versionCode）。**发布前需手动对齐**。

> 分发策略（与 APK 对齐）：凭据就绪后，iOS/HarmonyOS 版本化产物建议追加到同名 GitHub Release `vX.Y.Z`（`softprops/action-gh-release`），并保留固定名下载入口（如 `weixiaoxin.ipa` / `weixiaoxin.hap` 指向 `releases/latest/download/`），避免前端改地址。

## 三、签名与发布凭据（Secrets）

> 现状：凭据未配置，工作流产出**未签名**制品。凭据就绪后配置下列 Secrets 即可启用对应功能。

### iOS（Apple）

| Secret | 用途 |
|--------|------|
| `APPLE_TEAM_ID` | 开发者团队 ID |
| `APPLE_CERT_BASE64` | 分发证书 `.p12` 的 base64 |
| `APPLE_CERT_PASSWORD` | `.p12` 密码 |
| `APPLE_PROFILE_BASE64` | 描述文件 `.mobileprovision` 的 base64 |
| `APPLE_ASC_KEY_ID` / `APPLE_ASC_ISSUER_ID` / `APPLE_ASC_PRIVATE_KEY` | App Store Connect API Key（TestFlight 上传用） |

签名前还需：

1. 在 `frontend/ios/Runner.xcodeproj/project.pbxproj` 配置 `DEVELOPMENT_TEAM`。
2. 在 `frontend/ios/ExportOptions.plist` 填入真实 teamID / 证书名 / 描述文件 UUID（当前为占位符）。

### HarmonyOS（华为 AGC）

| Secret | 用途 |
|--------|------|
| `HUAWEI_SIGNING_CERT` | 发布证书 `.cer`（base64） |
| `HUAWEI_SIGNING_P12` | 证书库 `.p12`（base64） |
| `HUAWEI_SIGNING_PROFILE` | 发布 Profile `.p7b`（base64） |
| `HUAWEI_SIGNING_STORE_PASSWORD` | `.p12` 口令 |

签名前还需在 `frontend/harmonyos/build-profile.json5` 的 `signingConfigs` 填入证书信息（含 AGC 分配的 profile-id、certpath 等）。

## 四、HarmonyOS SDK 安装（CI）

`build-harmonyos` Job 流程：

1. `setup-java@v4`（temurin 17）+ `setup-node@v4`（20）。
2. 配置 npm 华为镜像源（`@ohos:registry` → `repo.harmonyos.com`）。
3. 下载 DevEco 命令行工具（含 hvigor / ohpm / sdkmgr），用 `sdkmgr install --accept-license` 装 HarmonyOS 5.0 (API 12) 组件。
4. `./hvigorw assembleHap`：项目内 `hvigor/hvigor-wrapper.js` 会自动安装匹配 `hvigor-config.json5` modelVersion 的 hvigor。

> ⚠️ 已知风险：华为 SDK 组件 URL / sdkmgr 参数随 CLI 版本变化，若首次运行失败，更新 `.github/workflows/build-mobile.yml` 中的下载地址与安装命令（已做降级容错）。

### 本地开发

- 安装 DevEco Studio（本机：`D:\Program Files\Huawei\DevEco Studio`，hvigor 6.23.6）。
- 构建：`hvigorw.bat assembleHap --mode module -p product=default -p buildMode=debug --no-daemon`（需 `HOS_SDK_HOME` / `DEVECO_SDK_HOME` 指向 DevEco 自带 SDK）。
- 产物：`entry/build/default/outputs/default/entry-default-unsigned.hap`。
- 注意：工程 `hvigor/hvigor-config.json5` 的 `dependencies` 为空，本地构建依赖 DevEco 自带 hvigor（6.23.6），勿删 `dependencies` 以外配置；CI 侧用命令行工具自带 `hvigorw`。

## 五、iOS 本地构建

```bash
cd frontend
flutter pub get
flutter build ios --release --no-codesign   # 未签名
flutter build ipa --release --export-options-plist=ios/ExportOptions.plist  # 签名
```
