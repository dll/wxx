# 学生用户导入与账号管理

## 权限

- `student` 与 `guest`：不能查看入口，也不能调用导入接口。
- `student_union`、`counselor`、`teacher`、`assistant`、`college_admin`、`school_admin`、`sys_admin`：可以导入学生 Excel。
- `college_admin` 及以上：可以查看用户列表。
- `school_admin` 及以上：可以修改姓名、角色、归属范围、归属 ID 和账号状态。
- `sys_admin`：可以重置任意用户密码。

前端只负责隐藏无权限操作；后端 `/api/v1/admin/users/import` 仍通过 capability 强制校验，学生直接请求会返回 403。

## Excel 格式

参考文件：`data/学生名单.xlsx`。

| 列名 | 是否必填 | 说明 |
|------|----------|------|
| 学号 | 是 | 登录账号、唯一键；未设置统一初始密码时也作为初始密码 |
| 姓名 | 是 | 用户显示名称 |
| 院系 | 否 | 保存到学生资料；学校/系统管理员导入时也用于确定归属 |
| 专业 | 否 | 保存到学生资料 |
| 班级 | 否 | 保存到学生资料 |
| 入学时间 / 入学日期 | 否 | 保存到学生资料 |
| 入学年份 | 否 | 保存到学生资料 |
| 角色 | 否 | 只能为空、`学生` 或 `student`，导入后统一为 `student` |

单次最多 5000 行，文件不超过 10MB，仅支持 `.xlsx`。空白行会忽略；重复学号按失败明细返回，不覆盖既有账号。

## 密码规则

- 登录必须同时提交账号和密码，不再自动创建账号，也不允许空密码登录。
- 导入时填写统一初始密码：长度至少 6 位，所有本批学生使用该密码。
- 导入时不填写统一初始密码：每名学生的初始密码为自己的学号。
- 数据库只保存 bcrypt 哈希，不保存明文密码。
- `disabled`、`pending`、`rejected` 状态账号不能登录。

历史开发种子账号由迁移 `029_student_user_import.sql` 补齐初始密码 `Wxx@2026`。该密码只用于本地与预发布验收，正式上线前必须由系统管理员逐一重置。

## 验收步骤

1. 使用非学生组织角色登录，在“我的 → 用户管理”打开导入页面。
2. 选择 `data/学生名单.xlsx`，留空统一密码并导入。
3. 核对导入结果总数、成功数、失败数和逐行明细。
4. 退出后使用样例学号和相同学号密码登录。
5. 验证空密码、错误密码、学生角色调用导入接口均被拒绝。
6. 学校管理员验证编辑用户资料和停用账号；系统管理员验证密码重置。
