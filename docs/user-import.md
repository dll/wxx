# 学生用户导入与账号管理

## 权限

- `student` 与 `guest`：不能查看入口，也不能调用导入接口。
- `student_union`、`counselor`、`teacher`、`assistant`、`college_admin`、`school_admin`、`sys_admin`：可以导入学生 Excel。
- `college_admin` 及以上：可以查看用户列表。
- `school_admin` 及以上：可以修改姓名、角色、归属范围、归属 ID 和账号状态。
- `sys_admin`：可以重置任意用户密码。

前端只负责隐藏无权限操作；后端 `/api/v1/admin/users/import` 仍通过 capability 强制校验，学生直接请求会返回 403。

## Excel 格式

参考文件：`data/学生名单.xlsx`、`data/2026级新生录取数据.xlsx`（16 列新生格式）。

| 列名 | 是否必填 | 说明 |
|------|----------|------|
| 学号 | 是 | 登录账号、唯一键；未设置统一初始密码时也作为初始密码 |
| 姓名 | 是 | 用户显示名称 |
| 院系 / 专业院系 | 否 | 保存到学生资料；学校/系统管理员导入时也用于确定归属 |
| 专业 | 否 | 保存到学生资料 |
| 班级 | 否 | 保存到学生资料 |
| 入学时间 / 入学日期 / 入校时间 | 否 | 保存到学生资料 |
| 入学年份 / 年级 | 否 | 保存到学生资料 |
| 角色 | 否 | 只能为空、`学生` 或 `student`，导入后统一为 `student` |
| 性别 | 否 | 保存到学生资料 |
| 校区 | 否 | 保存到学生资料；**为空默认「会峰校区」** |
| 学历层次 | 否 | 保存到学生资料 |
| 学制 | 否 | 保存到学生资料 |
| 预期毕业时间 | 否 | 保存到学生资料 |
| 学习形式 | 否 | 保存到学生资料 |
| 民族 | 否 | 保存到学生资料（公共字段） |
| 政治面貌 | 否 | 保存到学生资料（公共字段） |
| 出生年月 | 否 | 保存到学生资料（**隐私字段，仅本人/辅导员/管理员可见**） |

单次最多 5000 行，文件不超过 10MB，仅支持 `.xlsx`。空白行会忽略；重复学号按失败明细返回，不覆盖既有账号。

## 隐私分级（v2.0）

- **公共字段**（所有登录用户可见）：学号、姓名、学院、专业、班级、入学年份、性别、校区、学历层次、民族、政治面貌。
- **私密字段**（仅本人 + 辅导员/教师/管理员可见）：出生年月、手机号、微信、QQ、邮箱。
- 后端在用户列表接口按调用者角色脱敏（`model.SanitizePrivate`）；非授权角色（学生/学生会/游客）拿不到私密字段。
- 个人中心（`/user/profile`）只返回公共字段；本人详情（`/user/profile/detail`）返回全部。

## 密码规则

- 登录必须同时提交账号和密码，不再自动创建账号，也不允许空密码登录。
- 导入时填写统一初始密码：长度至少 6 位，所有本批学生使用该密码。
- 导入时不填写统一初始密码：每名学生的初始密码为自己的学号。
- 数据库只保存 bcrypt 哈希，不保存明文密码。
- `disabled`、`pending`、`rejected` 状态账号不能登录。

正式环境不得在文档或迁移脚本中公开统一初始密码；历史开发账号应由系统管理员在上线前逐一重置或停用。

## 验收步骤

1. 使用具备用户导入权限的正式账号登录，在“我的 → 用户管理”打开导入页面。
2. 选择符合模板的学生名单 Excel，留空统一密码并导入。
3. 核对导入结果总数、成功数、失败数和逐行明细。
4. 退出后使用导入学号和相同学号密码登录。
5. 验证空密码、错误密码、学生角色调用导入接口均被拒绝。
6. 学校管理员验证编辑用户资料和停用账号；系统管理员验证密码重置。
