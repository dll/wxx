## 3. 项目硬性约束（摘要）

以下内容承接《蔚小芯智能体》开篇约束，实施阶段 **不得默认违背**；若变更须走书面评审。

- **业务**：全院师生服务；多智能体管理中心、策略与元数据 **自研**；编排运行时 **可自部署开源框架（Eino）+ 自研封装**；关键链路可选 **Temporal**。
- **知识增强**：**必选**。主链路为 **Context Engine**：结构化数据（SQLite）+ **全文检索（FTS/BM25）** + 上下文拼装；**向量检索与 Agentic RAG 为可插拔**，按意图与触发策略启用；长文档按需 **Long Context**。
- **模型与部署**：使用 **智谱清言 / DeepSeek / 讯飞星火语音** 等 API；**不**本地部署大模型；**不**依赖 Coze 等第三方智能体 SaaS。
- **基础设施**：**不**强制 Docker/容器/集群；轻量化单机与服务化部署为主。
- **可信输出**：政策/条件类回答必须具备 **`sources` 可追溯**；低置信与未命中走兜底话术，**禁止编造条款与关键数字**。
- **全项目中文化**：所有文档、代码注释、Git 提交信息、错误提示、日志输出均使用中文。变量名与函数名用英文，但行内注释和文档注释必须中文。生成的 SKILL.md、README.md 等文件全中文。

## 4. Harness：AI 协作与工程纪律

蔚小芯研发全程采用 **Harness Engineering** 心智：**提示词 ⊂ 上下文 ⊂ Harness**。最小落地要求：

### 4.1 上下文架构

- 仓库根或 `WXX/` 内维护 **`AGENTS.md`**：百行级 **摘要 + 索引**，细则拆到 `WXX/docs/` 按需加载。
- 与业务相关的权威条文仍以《蔚小芯智能体》及 `docs/context-engine.md`、`specs/` 为准，避免在单文件堆积数千行规则。

### 4.2 执行能力

- 开发期可为 AI 助手配置 **MCP / Skills**（如文档检索、浏览器验证），但生产运行时第三方依赖须符合学院网络与安全策略。
- 对外部 API（学工、一表通、模型）的调用须有 **超时、重试与熔断** 策略（与智能体文档 §4、§9 一致）。

### 4.3 任务编排

- **先方案后编码**：复杂需求使用 Plan，经负责人确认后再改代码。
- **增量交付**：每完成可演示增量，更新对应说明文档并 **Git 提交**（检查点）；长会话污染上下文时 **新会话 + 关联文档** 恢复记忆。

### 4.4 反馈机制

- 合并前：**Lint、单元测试、必要时的 E2E/Browser 自测**；失败必须修复或标注豁免原因。
- 关键路径变更鼓励 **代码评审 / 双视角检查**（视同多 Agent 互审的人力版）。

### 4.5 架构护栏

- 区分 **风格 Lint** 与 **架构规则**（分层依赖、禁止 UI 直连 DB 等）；配合 **Pre-commit** 与版本历史，防止技术债无序膨胀。

## 5. 知识工程：Context Engine 为主，Wiki/RAG 为辅

### 5.1 产品侧（对用户可见知识）

严格执行《蔚小芯智能体》**§3.3 Context Engine**：

- **结构化优先** → **FTS/BM25 主召回** → **上下文拼装** → 模型生成；向量与 Agentic **按需**；手册类可 **Long Context**。
- **触发策略、Top-K、缓存策略、引用与元数据、切分规则** 以智能体文档 §3.3.x、§6.8 为准，不在本规范重复罗列数值时可指向 `WXX/docs/context-engine.md` 摘录表。

### 5.2 研发侧内部知识（可选 LLM Wiki 范式）

对照《RAGvsLLMwiki》：对于 **项目组内部** 的非实时资料（会议纪要、调研笔记、截图），可采用 **`knowledge/raw/` + `knowledge/wiki/` + 编译刷新** 的极简 wiki，用于人类与 AI 共读；**不得替代** 上线所需的 Context Engine 治理与审核流程。

### 5.3 何时考虑加重向量 / Graph / 混合检索

当命中率、兜底率、长尾同义问指标持续不达标时，按《RAGvsLLMwiki》第七节与智能体文档分期规划，**增量**引入向量补召回、重排或 Agentic，而非推翻主链路。

## 13. Flutter UI 设计与实现规范

> 蔚小芯前端以 **Material Design 3** 为设计语言基线，面向全校师生提供一致、美观、可访问的交互体验。

### 13.1 响应式布局

| 规则 | 说明 |
|------|------|
| **断点** | 手机 < 600dp → 平板 600–900dp → 桌面 > 900dp |
| **栅格** | 使用 `LayoutBuilder` + `ConstrainedBox`，内容区 `maxWidth` ≤ 900dp |
| **弹性面板** | 平板及以上使用 `NavigationRail` 替代 `BottomNavigationBar` |
| **安全区** | 所有页面包裹 `SafeArea`，键盘弹出时布局自适应不遮挡 |
| **文字缩放** | 使用 `MediaQuery.textScaler` 自适应系统字体大小，不硬编码字号 |

```dart
// 响应式布局示例
Widget build(BuildContext context) {
  final width = MediaQuery.of(context).size.width;
  final isDesktop = width > 900;
  return Scaffold(
    body: Row(
      children: [
        if (isDesktop) NavigationRail(...),
        Expanded(child: ConstrainedBox(
          constraints: BoxConstraints(maxWidth: isDesktop ? 900 : double.infinity),
          child: child,
        )),
      ],
    ),
  );
}
```

### 13.2 卡片与阴影

| 规则 | 说明 |
|------|------|
| **层级** | 使用 Material 3 `Elevation` token：`surface`(0) → `surface-container-low`(1) → `surface-container`(2) → `surface-container-high`(3) → `surface-container-highest`(4–5) |
| **阴影** | 卡片用 `Elevation.card`，悬浮用 `Elevation.modal`，忌用纯黑阴影 |
| **圆角** | 卡片 `BorderRadius.circular(16)`，小卡片 `12`，按钮 `24`（胶囊）或 `12` |
| **悬浮态** | `InkWell` + `hoverColor` + `splashColor`，点击时卡片上浮 2dp（`AnimatedScale` 或 `elevation` 过渡） |

```dart
// 标准卡片
Card(
  elevation: 1,
  shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(16)),
  child: Padding(
    padding: const EdgeInsets.all(16),
    child: ...,
  ),
)
```

### 13.3 磨砂玻璃质感

使用 `BackdropFilter` + `ImageFilter.blur` 实现半透明模糊背景，用于：
- 导航栏 / 底部栏
- 对话框遮罩
- 悬浮操作按钮区域

```dart
// 磨砂玻璃容器
ClipRRect(
  borderRadius: BorderRadius.circular(16),
  child: BackdropFilter(
    filter: ImageFilter.blur(sigmaX: 12, sigmaY: 12),
    child: Container(
      decoration: BoxDecoration(
        color: Theme.of(context).colorScheme.surface.withValues(alpha: 0.7),
        border: Border.all(color: Theme.of(context).colorScheme.outlineVariant.withValues(alpha: 0.3)),
        borderRadius: BorderRadius.circular(16),
      ),
      padding: const EdgeInsets.all(16),
      child: ...,
    ),
  ),
)
```

### 13.4 动画规范

| 规则 | 说明 |
|------|------|
| **页面转场** | 使用 `go_router` 内置转场或 `MaterialPageRoute` 默认滑动，时长 250–350ms |
| **微交互** | 按钮点击缩放 `AnimatedScale`、列表项插入/删除 `AnimatedList`、状态切换 `AnimatedSwitcher` |
| **加载态** | 骨架屏 > 转圈 > 空白。骨架屏用 `shimmer` 包或自绘灰色脉冲动画 |
| **反馈态** | 录音脉冲 (`FadeTransition`)、发送成功勾 (`ScaleTransition`)、错误抖动 (`AnimationController` + `Transform`) |
| **弹簧动画** | 自然交互推荐 `Curves.easeOutCubic` 或 `spring` 物理模型，不线性 |

```dart
// 列表项入场动画
AnimatedList(
  initialItemCount: items.length,
  itemBuilder: (context, index, animation) {
    return SizeTransition(
      sizeFactor: animation,
      child: _buildItem(items[index]),
    );
  },
)
```

### 13.5 图标系统

| 规则 | 说明 |
|------|------|
| **图标库** | 统一使用 `Material Icons`（`Icons.xxx`），不混杂第三方图标包 |
| **尺寸** | 导航图标 24dp，装饰图标 20dp，大图标（Hero/Logo）48–72dp |
| **语义** | 图标须与其功能语义一致（锁=密码、话筒=语音、校园=Logo） |
| **彩色图标** | 使用 `theme.colorScheme.primary` / `secondary` / `tertiary` 染色，不使用硬编码颜色 |
| **状态图标** | 选中/激活态用 `filled` 变体，非选中用 `outlined` 变体 |

```dart
// 图标使用规范
Icon(Icons.mic, size: 24, color: theme.colorScheme.primary)           // 语音按钮
Icon(Icons.school, size: 64, color: theme.colorScheme.primary.withValues(alpha: 0.7)) // Logo
Icon(isSelected ? Icons.chat : Icons.chat_outlined, size: 24)          // 导航项
```

### 13.6 表单与输入

| 规则 | 说明 |
|------|------|
| **输入框** | `OutlineInputBorder` + `BorderRadius.circular(12)`，prefixIcon/suffixIcon 对齐 |
| **标签** | 始终带 `labelText`（不依赖 hintText 占位），浮动标签样式 |
| **验证** | 失焦时校验 + 红色错误文本，提交时全量校验 + 首个错误自动聚焦 |
| **按钮** | 主操作 `FilledButton`，次要 `OutlinedButton`，文字 `TextButton`；危险操作用红色 |
| **按钮尺寸** | 全宽用 `SizedBox(width: double.infinity, height: 48)`，最小触摸区 48×48dp |
| **密码可见** | 密码框始终带 `suffixIcon` 切换可见性 (`visibility` / `visibility_off`) |
| **键盘** | `textInputAction: TextInputAction.next` 链式跳转，最后一项 `TextInputAction.send` |

### 13.7 列表与集合视图

| 规则 | 说明 |
|------|------|
| **分割线** | 使用 `Divider(height: 1, indent: 16)` 或 `theme.colorScheme.outlineVariant` 着色 |

### 13.8 暗黑模式

| 规则 | 说明 |
|------|------|
| **主题方案** | 使用 `MaterialApp.themeMode: ThemeMode.system` 跟随系统 |
| **颜色语义** | 所有颜色通过 `Theme.of(context).colorScheme` 取色，**禁止**硬编码 `Colors.black` / `Colors.white` |
| **对比度** | 暗色背景上的文字确保 WCAG AA（≥4.5:1），用 `onSurface` / `onSurfaceVariant` |
| **图片适配** | 暗色模式下 Logo 可能需要白色/浅色版本，或使用 `ColorFiltered` 反色 |
| **手动切换** | 个人中心提供手动切换入口（`ThemeMode.light/dark/system`），持久化到 `SharedPreferences` |

```dart
// 主题定义
MaterialApp(
  themeMode: ThemeMode.system,
  theme: ThemeData(
    colorSchemeSeed: const Color(0xFF1565C0), // 蔚小芯品牌蓝
    useMaterial3: true,
    brightness: Brightness.light,
  ),
  darkTheme: ThemeData(
    colorSchemeSeed: const Color(0xFF1565C0),
    useMaterial3: true,
    brightness: Brightness.dark,
  ),
)
```

### 13.9 代码结构与组件化

| 规则 | 说明 |
|------|------|
| **文件粒度** | 单文件 ≤ 400 行；超过则拆 widget 到 `widgets/` 目录或独立文件 |
| **组件分层** | `pages/`（路由页面）→ `widgets/`（可复用组件）→ `providers/`（状态）→ `services/`（数据层） |
| **提取原则** | 重复使用 2 次以上的 widget 提取为独立组件；页面内私有 widget 以 `_` 命名 |
| **Provider 用法** | 页面用 `context.watch<T>()` 监听变化，按钮回调用 `context.read<T>()` 触发动作 |
| **资源路径** | 图片/字体资源统一放在 `assets/` 子目录，路径常量定义在配置类中 |
| **import 排序** | dart: → package: → 项目内相对路径，每组间空行分隔 |
| **const 优化** | 所有不变的 widget 构造声明为 `const`，减少重建开销 |

```dart
// 标准页面文件骨架
import 'package:flutter/material.dart';
import 'package:provider/provider.dart';

import '../../providers/xxx_provider.dart';
import '../../widgets/xxx_card.dart';

/// 页面用途说明
class XxxPage extends StatelessWidget {
  const XxxPage({super.key});

  @override
  Widget build(BuildContext context) {
    final provider = context.watch<XxxProvider>();
    return Scaffold(
      appBar: AppBar(title: const Text('标题')),
      body: _buildBody(context, provider),
    );
  }

  Widget _buildBody(BuildContext context, XxxProvider provider) {
    if (provider.loading) return _buildSkeleton(context);
    if (provider.items.isEmpty) return _buildEmptyState(context);
    return _buildList(context, provider.items);
  }

  Widget _buildSkeleton(BuildContext context) { ... }
  Widget _buildEmptyState(BuildContext context) { ... }
  Widget _buildList(BuildContext context, List<Item> items) { ... }
}
```

### 13.10 质量检查清单

合并前逐项确认：

- [ ] 所有颜色通过 `Theme.of(context).colorScheme` 取色，无硬编码色值
- [ ] 所有文本通过 `theme.textTheme` 取字号，无硬编码 `fontSize`
- [ ] 桌面端（>900dp）布局正确，无溢出或挤压
- [ ] 暗黑模式下颜色对比度足够，无黑色不可见文本
- [ ] 空状态、加载态、错误态三种边界 UI 均有处理
- [ ] 动画使用 `Curves` 自然曲线，无线性动画
- [ ] 图标语义正确，尺寸符合规范
- [ ] 按钮最小触摸区 ≥ 48×48dp
- [ ] 列表项可滑动删除时带确认对话框
- [ ] `const` 装饰优化到位，无 lint 警告
