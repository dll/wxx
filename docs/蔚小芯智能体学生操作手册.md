# 蔚小芯智能体 · 系统与学生操作手册

> 版本：v1.0 · 2026-08-12
> 适用对象：系统使用者（教师/管理员）、**在校学生（尤其新生）**
> 正式入口：`https://wxx-agent.online`（Web）；备用入口：`https://wxx-agent.pages.dev`；另有 Android APK 与微信小程序端。

---

## 第一篇 · 系统简介

### 1.1 蔚小芯是什么

**蔚小芯**是滁州学院计算机科学与工程学院（网络空间安全学院）建设的**智慧学工 AI 助手**。
它把学校日常的**办事流程、政策制度、学习生活、思政成长、心理健康**等大量信息，通过大语言模型
组织成"一问一答"的智能服务。学生不需要翻遍通知和文件，直接向蔚小芯提问，就能得到**带来源、可追溯**的准确答复。

### 1.2 技术特点

| 特点 | 说明 |
|------|------|
| 智能问答 | 基于检索增强生成（Context Engine），答案**附带知识来源**，可追溯、可核对，不编造 |
| 多智能体协同 | 政策、办事流程、通用问答等多个智能体并行协同，回答更准确 |
| 角色化 | 学生、学生会、辅导员、教师、管理员各有专属能力 |
| 隐私分级 | 个人私密信息（手机号、出生年月等）仅本人、辅导员、管理员可见 |
| 安全可信 | 密码加密存储、首次登录强制改密、额度管控、审计日志可查 |
| 多端可用 | Web、Android APK、微信小程序，随时随地使用 |

### 1.3 技术栈

| 层 | 技术 |
|----|------|
| 前端 | Flutter / Dio / Provider / Hive |
| 后端 | Go / Gin / JWT / RBAC |
| 数据库 | SQLite（含 FTS 全文检索）→ 已迁移 MySQL + Redis |
| 检索 | 结构化查询 + FTS/BM25 为主，向量与 Agentic RAG 可插拔 |
| 编排 | 自研多智能体路由 + Eino（失败自动回退） |
| 大模型 API | 智谱 GLM、DeepSeek、讯飞（语音） |

### 1.4 蔚小芯在教育教学中的作用

1. **入学引导**：新生报到节点、校园导航、入学须知一站式解答。
2. **学习助手**：今日速览、课表、课程学情、学习周报、学习日记，帮助管理学习节奏。
3. **办事直达**：请假、奖学金、转专业、毕业离校等流程，问一句就知道怎么办、找谁、带什么材料。
4. **思政成长**：入党流程、政治学习、思想动态、新生计划，成长路径清晰可见。
5. **心理健康**：心理健康资源与情感关怀，遇到困扰可以安全倾诉。
6. **校园生活**：竞赛赛事、校园活动、志愿服务、校歌曲库、学术讲座。
7. **反馈闭环**：发现问题可一键反馈，管理员在线修复后闭环解决。

## 第二篇 · 学生操作手册（新生必读）

> 新生首次使用，请按顺序完成以下 6 步：**① 访问系统 → ② 登录 → ③ 修改初始密码 → ④ 认识首页 → ⑤ 提问 → ⑥ 查看额度**。

### 2.1 第一步：访问系统

**方式一（推荐，电脑/手机浏览器）**：打开浏览器，输入 `https://wxx-agent.online`，回车。

<div align="center">

**图 2-1  访问正式入口**

*【截图占位：浏览器地址栏输入 wxx-agent.online】*

</div>

**方式二（Android 手机）**：安装「蔚小芯」APK 后点击图标打开。

**方式三（微信小程序）**：微信搜索「蔚小芯」小程序（WebView 壳，加载同一前端），或扫描管理员下发的二维码。

> 提示：若校园网无法直连，请先连接校内网络，或使用备用入口 `https://wxx-agent.pages.dev`。

### 2.2 第二步：登录账号

登录页输入你的**学号**与**密码**，点击「登录」。

- **账号**：你的学号（如 `2026210421`）。
- **初始密码**：就是你的学号（学校统一导入，见《学生用户导入说明》）。

> ⚠️ 安全提醒：**初始密码等于学号，任何人都能猜到。请务必在登录后立即修改**（见 2.3 步）。

### 2.3 第三步：首次登录必须修改密码

为保障账号安全，**首次登录时系统会自动弹出「修改初始密码」对话框**，并且不可跳过。

<div align="center">

**图 2-3  首次登录强制修改密码**

*【截图占位：首次登录弹出的修改密码对话框（当前密码/新密码/确认新密码）】*

</div>

填写要求：

| 输入项 | 填什么 |
|--------|--------|
| 当前密码 | 你的学号（初始密码） |
| 新密码 | 自己设置的新密码，**至少 6 位**，建议字母+数字组合 |
| 确认新密码 | 再次输入新密码（需一致） |

点击「确认修改」：

- ✅ 修改成功：自动进入系统首页。
- ❌ 点击「退出登录」：不会进入系统，需重新登录并完成改密后才能使用。
- 密码忘记怎么办：联系辅导员或管理员重置。

> 若你的账号已被管理员重置过密码，第一次登录同样会要求设置新密码。

### 2.4 第四步：认识首页

登录后进入首页，可以看到：

- **顶部年级主题横幅**：系统按你的**入学年份**自动匹配年级专属配色——
  大一「迎新」青绿、大二「追梦」滁院蓝、大三「奋斗」橙、大四「创业」紫。
  让你一眼认出"我在蔚小芯的年级身份"。

- **底部主导航**（手机端）：首页 / 问小芯 / 办事 / 服务 / 我的。

### 2.5 第五步：向蔚小芯提问

点击底部「问小芯」，在输入框输入问题，例如：

- "入党需要什么条件？"
- "请假怎么办理？"
- "国家奖学金怎么申请？"
- "今天有什么课？"

<div align="center">

**图 2-5  问小芯对话界面**

回答会以 **AnswerCard** 形式呈现，包含：

- **结论**：直接回答你的问题。
- **步骤**：办事流程的分步指引（若适用）。
- **来源 sources**：答案依据的知识条目，点击可查看原文，**保证可追溯**。
- **追问建议**：可能感兴趣的后续问题。

> 提示：政策、流程类答案**必须带来源**，请以「来源」中的学校文件为准。若答案有误，点击回答下方的「纠错」反馈，管理员会修复。

### 2.6 第六步：AI 额度与个人 API Key

蔚小芯为每位学生提供**每月 AI 对话额度（默认 10,000 tokens）**，用于控制合理使用、防止滥用。

**查看用量**：我的 → 「AI 额度」。

<div align="center">

**图 2-6  AI 额度与绑定个人 API Key**

*【截图占位：AI 额度对话框（用量说明 + 提供商下拉 + API Key 输入框）】*

</div>

**额度用完怎么办？** 继续提问时会提示"本月 AI 对话额度已用完"。你可以二选一：

1. **等待下月额度重置**（每月 1 日恢复 10,000 tokens）。
2. **绑定你自己的 API Key**（推荐，可立即继续使用）：

   - 到 **我的 → AI 额度** 打开对话框。
   - 选择提供商（DeepSeek 或 智谱清言）。
   - 粘贴你自己的 API Key（形如 `sk-...`），点击「保存」。
   - 绑定后即可**继续使用，不消耗校内额度**。

> 在哪里获取 API Key？
> - DeepSeek：访问 `platform.deepseek.com` → API Keys → 创建新密钥。
> - 智谱清言：访问 `open.bigmodel.cn` → API Keys → 创建。
> - ⚠️ API Key 是敏感凭据，系统加密保存、**只用于你的请求**，不会显示明文，也请勿泄露给他人。

## 第三篇 · 常见问题（FAQ）

| 问题 | 解答 |
|------|------|
| 登录提示"账号或密码错误"？ | 检查学号是否正确；密码是否已修改过（用新密码登录）；确认账号未停用。 |
| 忘记密码怎么办？ | 联系辅导员或学院管理员重置。 |
| 登录后强制改密，但我点退出登录了？ | 重新登录，完成改密后才能进入系统。 |
| 问小芯回答不准/有误？ | 点击「纠错」反馈；同时以「来源」中的学校正式文件为准。 |
| AI 额度用完，绑定 Key 后仍提示超限？ | 确认 Key 保存成功；刷新页面后重试。 |
| 年级主题没变化？ | 确认「我的 → 年级主题自动切换」已开启；刷新页面。 |
| Web 打开空白？ | 强制刷新（Ctrl+F5）或清除浏览器缓存；换备用入口 `wxx-agent.pages.dev`。 |

## 第四篇 · 系统使用说明（面向教师/管理员，简要）

- **知识库治理**：管理员在「管理服务 → 知识库」维护政策/流程/FAQ 资源，经 AI 精修后发布。
- **用户管理**：「管理服务 → 用户管理」支持按角色/学院/专业/班级/入学年份/状态筛选，批量导入学生、重置密码、启用/停用。
- **学生导入**：按 Excel 模板（学号/姓名/院系/专业/班级/性别/校区/民族/政治面貌等 16 列）批量导入，初始密码为学号，**首次登录强制改密**。
- **反馈闭环**：「管理服务 → 反馈管理」查看用户反馈 → 在线修复（AI 定位代码/知识库）→ 复制结构化数据交 AI 修复 → 验证通过后标记已解决。
- **额度管理**：可在服务器环境配置 `MONTHLY_TOKEN_QUOTA_PER_USER`（默认 10000）调整每位用户月度 Token 额度。
