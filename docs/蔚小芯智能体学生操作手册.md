## 第一篇 · 系统简介

### 1.1 蔚小芯是什么

**蔚小芯**是滁州学院计算机科学与工程学院（网络空间安全学院）建设的**智慧学工 AI 助手**。
它把学校日常的**办事流程、政策制度、学习生活、思政成长、心理健康**等大量信息，通过大语言模型
组织成"一问一答"的智能服务。学生不需要翻遍通知和文件，直接向蔚小芯提问，就能得到**带来源、可追溯**的准确答复。

**一句话**：你的 24 小时校园 AI 学伴——不懂就问，办事直达，越用越懂你。

### 1.2 技术特点

| 特点 | 说明 |
|------|------|
| 智能问答 | 基于检索增强生成（Context Engine），答案**附带知识来源**，可追溯、可核对，不编造 |
| 多智能体对话 | 政策、办事流程、通用问答、学情分析等多个智能体，可**自由切换**问答对象 |
| 越用越聪明 | 个性化推荐引擎：根据你的提问历史、FTS 检索与热门兜底，为你推荐关注内容 |
| 热门话题 | AI 聚合全校高频提问，自动聚类生成热点标签与趋势，一眼看大家都在问什么 |
| 角色化 | 学生、学生会、辅导员、教师、管理员各有专属能力 |
| 隐私分级 | 个人私密信息（手机号、出生年月等）仅本人、辅导员、管理员可见 |
| 安全可信 | 密码加密存储、首次登录强制改密、额度管控、审计日志可查 |
| 多端可用 | Web、Android APK、微信小程序，随时随地使用 |

### 1.3 技术栈

| 层 | 技术 |
|----|------|
| 前端 | Flutter / Dio / Provider / Hive |
| 后端 | Go / Gin / JWT / RBAC |
| 数据库 | SQLite（含 FTS 全文检索）→ 已迁移 MySQL + Redis |
| 检索 | 结构化查询 + FTS/BM25 为主，向量与 Agentic RAG 可插拔 |
| 编排 | 自研多智能体路由 + Eino（失败自动回退） |
| 大模型 API | 智谱 GLM、DeepSeek、讯飞（语音） |

### 1.4 蔚小芯在教育教学中的作用

1. **入学引导**：新生报到节点、校园导航、入学须知一站式解答。
2. **学习助手**：今日速览、课表、课程学情、学习周报、学习日记，帮助管理学习节奏。
3. **办事直达**：请假、奖学金、转专业、毕业离校等流程，问一句就知道怎么办、找谁、带什么材料。
4. **思政成长**：入党流程、政治学习、思想动态、新生计划，成长路径清晰可见。
5. **心理健康**：心理健康资源与情感关怀，遇到困扰可以安全倾诉。
6. **校园生活**：竞赛赛事、校园活动、志愿服务、校歌曲库、学术讲座、学习搭子。
7. **反馈闭环**：发现问题可一键反馈，管理员在线修复后闭环解决。

## 第二篇 · 学生操作手册（新生必读）

> 新生首次使用，请按顺序完成以下 6 步：**① 访问系统 → ② 登录 → ③ 修改初始密码 → ④ 认识首页 → ⑤ 智能体对话 → ⑥ 查看额度**。

### 2.1 第一步：访问系统

**方式一（推荐，电脑/手机浏览器）**：打开浏览器，输入 `https://wxx-agent.online`，回车。

<div align="center">

**图 2-1  访问正式入口**

**方式二（Android 手机）**：安装「蔚小芯」APK 后点击图标打开。

**方式三（微信小程序）**：微信搜索「蔚小芯」小程序（WebView 壳，加载同一前端），或扫描管理员下发的二维码。

> 提示：若校园网无法直连，请先连接校内网络，或使用备用入口 `https://wxx-agent.pages.dev`。

### 2.2 第二步：登录账号

登录页输入你的**学号**与**密码**，点击「登录」。

- **账号**：你的学号（如 `2026210421`）。
- **初始密码**：就是你的学号（学校统一导入）。

### 2.3 第三步：首次登录必须修改密码

为保障账号安全，**首次登录时系统会自动弹出「修改初始密码」对话框**，并且不可跳过。

<div align="center">

**图 2-3  首次登录强制修改密码**

*【截图占位：首次登录弹出的修改密码对话框（当前密码/新密码/确认新密码）】*

</div>

填写要求：

| 输入项 | 填什么 |
|--------|--------|
| 当前密码 | 你的学号（初始密码） |
| 新密码 | 自己设置的新密码，**至少 6 位**，建议字母+数字组合 |
| 确认新密码 | 再次输入新密码（需一致） |

点击「确认修改」：

- ✅ 修改成功：自动进入系统首页。
- ❌ 点击「退出登录」：不会进入系统，需重新登录并完成改密后才能使用。
- 密码忘记怎么办：联系辅导员或管理员重置（管理员可在用户管理中一键重置）。

> 若你的账号已被管理员重置过密码，第一次登录同样会要求设置新密码。

  大一「迎新」青绿、大二「追梦」滁院蓝、大三「奋斗」橙、大四「创业」紫。

### 2.5 第五步：智能体对话（问小芯）

点击底部「问小芯」，这是蔚小芯的核心功能——**多智能体对话**。

#### 2.5.1 选择智能体

对话页顶部有一个**智能体选择器**：默认使用「智能体」（多智能体协同），你也可以点击切换为其他专用智能体，例如：

- **政策智能体**：问政策、制度、条件，答案附政策原文来源。
- **办事流程智能体**：问手续怎么办，返回分步指引（步骤/材料/地点/联系人）。
- **通用问答智能体**：日常问题自由问答。
- 其余按学校配置的智能体（以对话页实际列表为准）。

#### 2.5.3 看懂回答（AnswerCard）

#### 2.5.4 对话管理

- **新建对话**：点击输入框旁的新建图标，开始新对话。
- **历史对话**：桌面端左侧 / 手机端顶部可查看历史会话，随时回到之前的问题。
- **删除对话**：删除后不再占用列表，不留痕迹。

### 2.6 热门话题与社区

点击「服务 → 校园社区」或对应入口，可进入：

- **问答广场**：浏览/参与同学们的问题讨论，也可以自己提问。
- **热门话题**：AI 自动聚合全校高频提问，生成**热点标签**与**趋势**——一眼看大家都在关心什么。
- **问答排行**：看看哪些问题最受关注、哪些回答最有价值。
- **站内私聊**：与同学一对一交流。

## 第三篇 · 常见问题（FAQ）

| 问题 | 解答 |
|------|------|
| 登录提示"账号或密码错误"？ | 检查学号是否正确；密码是否已修改过（用新密码登录）；确认账号未停用。 |
| 忘记密码怎么办？ | 联系辅导员或学院管理员，管理员在「用户管理」中一键重置。 |
| 登录后强制改密，但我点退出登录了？ | 重新登录，完成改密后才能进入系统。 |
| 为什么问小芯回答带"来源"？ | 政策、流程类答案必须引用学校知识库原文，保证准确、可追溯。 |
| 回答有误怎么办？ | 点击回答下方的「反馈」纠错，写明问题，管理员会在线修复。 |
| AI 额度用完，绑定 Key 后仍提示超限？ | 确认 Key 已保存；刷新页面后重试。 |
| 年级主题没变化？ | 确认「我的 → 年级主题自动切换」已开启；刷新页面。 |
| 热门话题是怎么来的？ | AI 自动聚合全校高频提问并聚类成热点标签，非人工编辑。 |
| Web 打开空白？ | 强制刷新（Ctrl+F5）或清除浏览器缓存；换备用入口 `wxx-agent.pages.dev`。 |
| 我的私密信息（手机号/出生年月）别人能看到吗？ | 不会。仅本人、辅导员、管理员可见，其他用户不可见。 |

## 第四篇 · 系统使用说明（面向教师/管理员，简要）

- **知识库治理**：管理员在「管理服务 → 知识库」维护政策/流程/FAQ 资源，经 AI 精修后发布。
- **智能体管理**：「管理服务 → 智能体」可注册、配置、启停 AI 智能体。
- **用户管理**：「管理服务 → 用户管理」支持按角色/学院/专业/班级/入学年份/状态筛选，批量导入学生、**一键重置密码**、启用/停用。
- **学生导入**：按 Excel 模板（16 列）批量导入，初始密码为学号，**首次登录强制改密**。
- **反馈闭环**：「管理服务 → 反馈管理」查看反馈 → 在线修复（AI 定位）→ 复制结构化数据交 AI 修复 → 验证通过后标记已解决。
- **额度管理**：服务器环境配置 `MONTHLY_TOKEN_QUOTA_PER_USER`（默认 10000）调整月度 Token 额度。
