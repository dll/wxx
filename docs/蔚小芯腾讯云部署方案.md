# 蔚小芯腾讯云部署方案

> **创建日期**：2026-07-31  
> **当前架构**：前端 CF Pages + 后端腾讯云 Lighthouse + 本地 SQLite  
> **历史方案**：Vercel Serverless + Turso（已停用，仅作归档）

---

## 一、架构总览

```
用户设备（浏览器 / Android APK）
    │
    ▼
Cloudflare Pages（www.wxx-agent.online / wxx-agent.pages.dev）
    ├── /*          → Flutter Web 静态文件（Served by CF CDN）
    └── /api/*      → CF Pages Functions（JWT 边缘验证）
                        ├── 公开路由 → 直接代理到 Go 后端
                        └── 私密路由 → JWT 验证 → 代理到 Go 后端
                             │
                             ▼
                    Caddy 反向代理（TLS 自动签发）
                             │
                             ▼
                    Go 后端（systemd 常驻，:8080）
                             │
                             ▼
                    本地 SQLite（/opt/wxx/data/wxx.db）含 FTS5
```

| 层次 | 技术 | 托管方式 | 公网地址 |
|------|------|---------|---------|
| 前端 | Flutter Web + CF Pages Static | Cloudflare Pages，免费 | `www.wxx-agent.online` |
| API 网关 | CF Pages Functions（JWT 鉴权 + 代理） | Cloudflare Pages，免费 | `/api/*` 路由 |
| 反向代理 | Caddy 2 + Let's Encrypt | 腾讯云 Lighthouse | `:443` → `:8080` |
| 后端 API | Go/Gin 二进制 | systemd 常驻，腾讯云 Lighthouse | `:8080` |
| 数据库 | SQLite（WAL 模式，含 FTS5） | 本地 `/opt/wxx/data/wxx.db` | 本地文件 |

## 三、部署步骤

### 3.1 服务器初始化

```bash
# 连接到服务器
ssh root@129.211.223.113

# 系统更新
apt-get update && apt-get install -y curl build-essential git

# 安装 Go
wget -q https://go.dev/dl/go1.22.5.linux-amd64.tar.gz
tar -C /usr/local -xzf go1.22.5.linux-amd64.tar.gz
export PATH=$PATH:/usr/local/go/bin

# 安装 Caddy
apt install -y debian-keyring debian-archive-keyring
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/gpg.key' | gpg --dearmor > /usr/share/keyrings/caddy-stable-archive-keyring.gpg
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/debian.deb.txt' | tee /etc/apt/sources.list.d/caddy-stable.list
apt update && apt install -y caddy
```

### 3.2 部署应用

```bash
# 克隆仓库
mkdir -p /opt/wxx
cd /opt/wxx
git clone https://github.com/dll/wxx.git .

# 编译 Go 后端（必须带 FTS5 tag）
export GOPROXY=https://goproxy.cn,direct
cd /opt/wxx/server
go build -tags fts5 -o /opt/wxx/wxx-server ./cmd/server
```

### 3.3 配置环境变量

创建 `/etc/wxx/env`：

```ini
APP_MODE=production
APP_PORT=8080
SQLITE_PATH=/opt/wxx/data/wxx.db
JWT_SECRET=<64位随机十六进制字符串>
DEEPSEEK_API_KEY=<你的DeepSeek密钥>
ZHIPU_API_KEY=<你的智谱密钥>
XF_API_KEY=<你的讯飞密钥>
XF_API_SECRET=<你的讯飞密钥>
CORS_ALLOWED_ORIGINS=https://www.wxx-agent.online,https://wxx-agent.pages.dev
```

**注意**：`/opt/wxx/data/` 目录需提前创建，`wxx.db` 会在首次运行时自动初始化。

### 3.4 systemd 服务

创建 `/etc/systemd/system/wxx.service`：

```ini
[Unit]
Description=蔚小芯 Go 后端服务
After=network.target

[Service]
Type=simple
EnvironmentFile=/etc/wxx/env
ExecStart=/opt/wxx/wxx-server
Restart=always
RestartSec=5
WorkingDirectory=/opt/wxx

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload
systemctl enable --now wxx
systemctl status wxx
```

### 3.5 Caddy HTTPS 反向代理

创建 `/etc/caddy/Caddyfile`：

```
www.wxx-agent.online {
    reverse_proxy localhost:8080
}
```

```bash
systemctl enable --now caddy
```

### 3.6 防火墙

在腾讯云 Lighthouse 控制台 → 防火墙 → 放通：

| 端口 | 协议 | 用途 |
|------|------|------|
| 22 | TCP | SSH |
| 80 | TCP | Let's Encrypt HTTP 验证 |
| 443 | TCP | HTTPS |
| 8080 | TCP | CF Functions 后端代理 |

## 四、前端部署（Cloudflare Pages）

### 4.1 Pages 项目信息

| 项目 | 值 |
|------|-----|
| 项目名 | `wxx-agent` |
| 生产分支 | `main` |
| 构建命令 | `flutter build web --release --web-renderer canvaskit --dart-define=BAIDU_MAP_AK=<AK>` |
| 构建输出 | `frontend/build/web` |
| Functions 目录 | `frontend/functions/` |

### 4.2 CF Pages 环境变量（`wrangler pages secret put` 或 Dashboard 设置）

| 变量 | 值 | 用途 |
|------|-----|------|
| `GO_BACKEND_URL` | `http://129.211.223.113:8080` | CF Functions 代理到 Go 后端 |
| `JWT_SECRET` | 与服务端 `/etc/wxx/env` 中相同 | JWT 签名验证一致 |
| `BAIDU_MAP_AK` | 百度地图 Web 端 AK | Campus 地图渲染（Web + Android）|

### 4.3 CI 自动部署

每次 push 到 `main` 的 `frontend/**` 触发 `.github/workflows/deploy-frontend.yml`：

1. 检出代码 → 安装 Flutter 3.22.0
2. `flutter build web --release`（注入 BAIDU_MAP_AK）
3. 安装 Functions 依赖（`bcryptjs`）
4. 复制 Functions 到构建目录
5. 删除 Flutter 生成的 `_routes.json`
6. `wrangler pages deploy` 部署到 CF Pages

### 4.4 手动部署

```bash
# 在 /opt/wxx/frontend
flutter build web --release --web-renderer canvaskit \
  --dart-define=BAIDU_MAP_AK=<你的百度地图AK>

# 准备 Functions
npm install --omit=dev
mkdir -p build/web/functions
cp -r functions/* build/web/functions/
rm -f build/web/_routes.json     # 删除 Flutter 版本的 _routes.json

# 部署到 CF Pages
npx wrangler pages deploy build/web \
  --project-name wxx-agent --commit-dirty=true
```

## 五、维护与运维

### 5.1 SQLite 备份（**重要**）

```bash
# 写入 cron（每天凌晨 2 点备份）
crontab -e
# 添加：
0 2 * * * cp /opt/wxx/data/wxx.db /opt/wxx/data/backup/wxx.$(date +\%Y\%m\%d).db && \
         find /opt/wxx/data/backup/ -name 'wxx.*.db' -mtime +7 -delete
```

### 5.2 健康检查

```bash
# Go 后端
curl -s http://localhost:8080/health
# 预期：{"status":"healthy","fts5":"ok","sqlite":"ok","latency_us":58}

# CF Pages + 完整链路
curl -s https://www.wxx-agent.online/api/v1/version/check
# 预期 200 + JSON 响应
```

### 5.3 后端更新

```bash
cd /opt/wxx
git pull
export GOPROXY=https://goproxy.cn,direct
go build -tags fts5 -o /opt/wxx/wxx-server ./server/cmd/server
systemctl restart wxx
systemctl status wxx
```

### 5.4 前端更新

- 推送到 `main` → GitHub Actions 自动部署（网站 + APK）
- 或手动部署（见 4.4 节）

### 5.5 日志

```bash
# Go 后端日志
journalctl -u wxx -f

# Caddy 访问日志
journalctl -u caddy -f
```

## 七、架构对比

| 维度 | 当前方案（Lighthouse + SQLite） | 历史方案（Vercel + Turso） |
|------|------|------|
| 后端运行 | systemd 常驻，无冷启动 | Vercel Serverless，有冷启动 |
| 数据库 | 本地 SQLite，~58µs | Turso 云端，~50ms |
| FTS5 | ✅ 可用 | ❌ Turso 不支持 |
| LLM 长请求 | ✅ 无限制 | ⚠️ Serverless 超时 |
| 运维成本 | 中（月¥150–220） | 低（按量计费） |
| APK 分发 | GitHub Artifacts + 直接下载 | 不适用 |
