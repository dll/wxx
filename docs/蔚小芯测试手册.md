## 1. 环境与访问

### 1.1 访问地址

| 渠道 | 地址 | 说明 |
|------|------|------|
| Web 浏览器 | `https://wxx-agent.pages.dev` | Cloudflare Pages 托管的主站 |
| 微信小程序 | 搜索「蔚小芯」或扫码进入 | WebView 壳加载同一前端 |
| 备用地址 | `https://wxx.pydaydayup.xyz` | Vercel 托管（旧址） |

### 1.2 支持的浏览器

- Chrome / Edge（最新版，推荐）
- Safari（iOS 15+）
- 微信内置浏览器
- 不支持 IE

### 1.3 测试前准备

- [ ] 确保网络畅通，能访问上述 URL
- [ ] 准备一个未登录过的浏览器（或清除 `localStorage`）
- [ ] 记录所有测试结果（可用附录模板）
- [ ] 工具：浏览器 DevTools（F12）查看网络请求与 Console
