# 内置账号与登录问题运维指引

> 适用范围：腾讯云 Lighthouse（`129.211.223.113`）上的生产库。
> 原则：**内置账号的状态与口令属于数据/运维层面，代码迁移不做强制覆盖**（避免在仓库硬编码口令或改动账号角色）。

## 1. 内置测试账号

清单见 `docs/蔚小芯角色功能所需材料.md` 附录 12（默认密码 `wxx@2025`，由迁移 029 统一设定 bcrypt 哈希）。
生产环境正式账号请用「用户管理」导入/重置，不以仓库内账号为准。

## 2. 报错：账号尚未启用或已被停用

**根因**：登录逻辑先查账号状态再验密码（`server/internal/service/auth_service.go`）：
```go
if user.Status != "active" {
    return nil, fmt.Errorf("%w：当前状态为 %s", ErrAccountUnavailable, user.Status)
}
```
`users.status` 列默认是 `active`（迁移 025），因此只有该账号被停用/状态异常时才会触发此报错——**不是代码 bug，是库内数据问题**。

## 3. 生产库修复方法

### 方式 A：SSH 直改（推荐）

```bash
# 1. 找生产库路径（/etc/wxx/env 里的 SQLITE_PATH，通常 /opt/wxx/data/wxx.db）
grep SQLITE_PATH /etc/wxx/env

# 2. 启用内置账号（示例 admin；其余内置账号同理）
sqlite3 /opt/wxx/data/wxx.db "
UPDATE users SET status='active' WHERE username IN ('admin','sysadmin','schooladmin','collegeadmin','counselor_cs','student_cs');
"

# 3. 重启后端使生效
sudo systemctl restart wxx-server
```

### 方式 B：用可用管理账号在界面启用

若 `sysadmin` / `schooladmin`（密码 `wxx@2025`）仍可登录，进「用户管理」把目标账号状态改为启用、重置密码即可，无需动库。

### 方式 C：重置某账号密码

```bash
# 在服务器上生成 bcrypt 哈希后更新（或用「用户管理」重置）
sqlite3 /opt/wxx/data/wxx.db "UPDATE users SET password_hash='<bcrypt哈希>' WHERE username='admin';"
```
