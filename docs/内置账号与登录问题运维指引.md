# 内置账号与登录问题运维指引

> 适用范围：腾讯云 Lighthouse（`129.211.223.113`）上的生产库（MySQL 8.0，非 SQLite）。
> 原则：内置账号的状态与口令属于数据/运维层面；**内置账号密码统一为 `Wxx@2026`**，
> 启动时由 `fixPasswordHashes`（`server/pkg/app/sync.go`）统一重置，避免在仓库散落口令。

## 1. 内置账号与统一密码

内置种子账号（admin / schooladmin / collegeadmin / sysadmin / counselor_cs / counselor_math /
counselor1 / counselor2 / stunion / student_cs / student_math / student1 / teacher1 / assistant1）
**统一登录密码为 `Wxx@2026`**。

- 每次服务启动时，`fixPasswordHashes` 会把上述种子账号（用户名在白名单内）的密码哈希**无条件重置为 `Wxx@2026`**
  （即使旧哈希是有效 bcrypt 也会覆盖），保证内置账号随时可用统一密码登录。
- **真实导入的账号（学生/教师等）不受影响**，密码保持导入/设置时的值；正式账号请用「用户管理」导入/重置。
- 重置工具：`server/cmd/reset-seed`（历史 SQLite 版，生产已用 MySQL 启动自修复替代，一般无需手工跑）。

## 2. 报错：账号尚未启用或已被停用

**根因**：登录逻辑先查账号状态再验密码（`server/internal/service/auth_service.go`）：
```go
if user.Status != "active" {
    return nil, fmt.Errorf("%w：当前状态为 %s", ErrAccountUnavailable, user.Status)
}
```
`users.status` 列默认是 `active`（迁移 025），因此只有该账号被停用/状态异常时才会触发此报错——**不是代码 bug，是库内数据问题**。

## 3. 生产库修复方法（MySQL）

### 方式 A：SSH 直改生产 MySQL（推荐）

```bash
# 1. 取生产 MySQL 连接信息（/etc/wxx/env）
DB_PW=$(grep '^DB_PASSWORD=' /etc/wxx/env | cut -d= -f2-)
DB=$(grep '^DB_NAME=' /etc/wxx/env | cut -d= -f2-)

# 2. 启用内置账号（须走 TCP -h127.0.0.1；localhost socket 认证会失败）
mysql -h127.0.0.1 -uwxx -p"$DB_PW" "$DB" \
  -e "UPDATE users SET status='active' WHERE username IN ('admin','sysadmin','schooladmin','collegeadmin','counselor_cs','student_cs');"

# 3. 重启后端使生效（服务名是 wxx，不是 wxx-server）
sudo systemctl restart wxx
```

### 方式 B：用可用管理账号在界面启用

若 `sysadmin` / `schooladmin`（密码 `Wxx@2026`）仍可登录，进「用户管理」把目标账号状态改为启用、重置密码即可，无需动库。

### 方式 C：重置某账号密码

内置账号直接用 `Wxx@2026`（启动自修复会统一）；真实账号用「用户管理」重置，或：
```bash
# 生成 bcrypt 哈希后更新（或用「用户管理」重置）
DB_PW=$(grep '^DB_PASSWORD=' /etc/wxx/env | cut -d= -f2-)
DB=$(grep '^DB_NAME=' /etc/wxx/env | cut -d= -f2-)
HASH=$(htpasswd -bnBC 10 "" '新密码' | tr -d ':\n')
mysql -h127.0.0.1 -uwxx -p"$DB_PW" "$DB" -e "UPDATE users SET password_hash='$HASH' WHERE username='目标账号';"
```

## 4. 说明

- 生产已从 SQLite 迁移到 **MySQL 8.0.46**（`docs/database-migration-mysql.md`），旧 SQLite 指引（`sqlite3`、`SQLITE_PATH`、`/opt/wxx/data/wxx.db`）已过时，勿再使用。
- 系统服务名是 `wxx`（systemd `/etc/systemd/system/wxx.service`，`ExecStart=/opt/wxx/wxx-server`），不是 `wxx-server`。
- 内置账号口令由启动自修复统一管理；如需改动，改 `server/pkg/app/sync.go` 的种子白名单 + `seedPassword`，走 CI/CD 部署生效，不要在库手工改（会被启动重置覆盖）。
