# 蔚小芯用户数字画像升级说明

> 版本：v4.0 | 日期：2026-09-01

## 定位

用户数字画像不再只是分数雷达图，而是蔚小芯基于 Context Engine 真实业务记录生成的「AI 原生成长画像」：围绕入学—在校—毕业全生命周期，帮助学生理解当前成长阶段、数据依据与下一步行动。

## 画像输出

- **五维成长结构**：学业、能力、思想、情感、社交；每个维度返回真实指标证据。
- **成长阶段**：入学适应、在校成长、能力发展、方向选择；阶段由实际记录和规划完成情况推导，不做人格式化定型。
- **成长标签**：如“成长数据待建立”“正在把计划变成行动”“有潜力的实践探索者”，用于解释而非评价学生。
- **数据覆盖度**：明确五维中有真实数据支撑的比例，避免用 0 分冒充真实结论。
- **AI 解读与行动建议**：继续沿用 LLM 解读、失败规则兜底；建议可执行、可追踪，不编造政策条款。

## 可信与隐私边界

- 无数据维度显示“数据积累中”，不生成伪分数、不把缺失当作低能力。
- 情感维度仅用于关怀提醒和成长支持，不作心理疾病诊断或人格定型。
- 画像只服务本人和经过 RBAC 授权的育人角色；管理侧必须按学院/职责范围过滤。
- 画像生成来源于真实业务聚合，后续可接入 Context Engine 的 sources/审计链路扩展解释性。

## 前端呈现

数字孪生页新增成长身份卡，展示成长阶段、成长标签、数据覆盖度与解释边界；原有五维雷达、AI 分析、成长建议和数字人形象继续保留。
