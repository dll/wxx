# 蔚小芯用户数字画像升级说明

> 版本：v4.1 | 日期：2026-09-01

## 设计定位

参考校园数字人陪伴、工作伙伴式自然播报和工作台式指标反馈的交互方向，蔚小芯采用“成长数字人 + 可解释画像”方案：数字人不是静态头像，也不是给学生贴标签，而是把真实的学习、实践、思想、情感与校园参与记录转化为可理解、可行动的成长反馈。

## 数字人交互

- **人体打散组装动画**：每个动画周期开始时，头部与身体从两侧分离位置缓动归位，随后进入漂浮、呼吸、眨眼、光环脉冲和粒子循环，表达“成长数据持续汇聚、蔚小芯持续陪伴”。
- **五维指标循环**：底部保留学业、能力、思想、情感、社交总览，每 4 秒聚焦一个维度并平滑切换名称与分数。
- **语音播报**：点击音量按钮播报当前聚焦维度；Web 使用浏览器语音能力，Android/iOS 使用后端 TTS 与音频播放器。再次点击可停止。
- **角色化形象**：数字人颜色、服饰和配饰由角色与真实画像数据驱动，学生、教师、辅导员、管理员保持可识别差异。
- **校园语境**：保留校园建筑、校徽蓝、学位服、书本、徽章、星光等蔚小芯视觉元素。

## 画像输出

- **成长阶段**：入学适应、在校成长、能力发展、方向选择。
- **成长标签**：基于真实记录生成，不做人格定型。
- **数据覆盖度**：明确五维中有真实数据支撑的比例。
- **真实指标证据**：每个维度保留用于生成结论的指标摘要。
- **AI 解读与行动建议**：沿用 LLM 解读与规则兜底，建议面向下一步行动，不编造政策或数据。

## 可信与隐私边界

无真实数据的维度显示“数据积累中”，不生成伪分数；情感维度仅用于关怀支持，不进行心理疾病诊断；画像只向本人及经过 RBAC 授权的育人角色提供。
