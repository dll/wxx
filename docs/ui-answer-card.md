# AnswerCard 与导出审计（摘录）

> 详见同目录 **`蔚小芯智能体.md`** §3.5。

## AnswerCard 最小结构

- 主回答：一句话结论 + 3～5 条要点  
- **步骤清单**（可勾选）：材料、入口、截止时间、地点  
- **`sources`**：标题、链接、版本、适用对象  
- **风险提示**、**建议追问**、可执行动作（收藏、转发、导出等）

## 导出审计（硬要求）

所有导出记录：**导出人、角色、时间、格式、是否含敏感字段、traceId**。  
导出内容须含：**版本号、`sources`、生成时间、适用范围**；学院/学校级导出启用水印与二次确认（总纲 §3.5.4）。

## 分期形态

P0：文本 + 步骤清单 + 引用卡；P1：TTS、长图；P2：材料模板等 — 见总纲 §3.5.2。
