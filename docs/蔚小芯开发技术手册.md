## 1. 项目概述

**蔚小芯**是滁州学院信息学院研发的智慧校园 AI 学工助手，面向全院师生提供智能问答、知识查询、情感预警、语音交互等服务。

### 1.1 核心架构

```
┌─────────────────────────────────────────────────────────┐
│                    Flutter 客户端                        │
│              (Web / Android / iOS)                       │
└───────────────────────┬─────────────────────────────────┘
                        │ HTTP/SSE
                        ▼
┌─────────────────────────────────────────────────────────┐
│                  Go/Gin 后端服务                         │
│   ┌─────────┐  ┌──────────┐  ┌─────────────────────┐   │
│   │ Handler │→ │ Service  │→ │ Repository          │   │
│   └─────────┘  └──────────┘  └─────────────────────┘   │
│                        │                                │
│                        ▼                                │
│   ┌─────────────────────────────────────────────────┐   │
│   │           Context Engine                        │   │
│   │   SQLite + FTS5/BM25 + 上下文拼装               │   │
│   └─────────────────────────────────────────────────┘   │
└───────────────────────┬─────────────────────────────────┘
                        │ API 调用
                        ▼
┌─────────────────────────────────────────────────────────┐
│              第三方大模型 API                            │
│         智谱清言 / DeepSeek / 讯飞星火                   │
```

### 3.1 操作系统

| 系统 | 最低版本 | 推荐 |
|------|---------|------|
| Windows | Windows 10 | Windows 11 |
| macOS | macOS 12 | macOS 14+ |

### 3.2 安装 Go

```bash
# Windows (使用 scoop)
scoop install go

# macOS (使用 brew)
brew install go

# Linux (使用 apt)
sudo apt update && sudo apt install golang-go

# 验证安装
go version    # 输出: go version go1.23.x ...
```

### 3.3 安装 Flutter

```bash
# Windows/macOS: 从官网下载 Flutter SDK
# https://docs.flutter.dev/get-started/install

# 或使用 Git 克隆
git clone https://github.com/flutter/flutter.git -b stable
export PATH="$PATH:`pwd`/flutter/bin"

# 验证安装
flutter doctor    # 按提示修复所有 ✗ 项

# 国内镜像（可选，加速下载）
export FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn
export PUB_HOSTED_URL=https://pub.flutter-io.cn
```

### 3.4 安装 Node.js (Vercel 部署需要)

```bash
# 下载 Node.js 18+ 或使用 nvm
# https://nodejs.org/

# 验证
node -v
npm -v
```

```bash

# 登录 Vercel 账号

```

### 3.6 安装 SQLite (可选，调试用)

```bash

# https://www.sqlite.org/download.html
```

## 5. 环境配置

### 5.1 创建 .env 文件

```bash
# 从模板复制
cp .env.example .env
```

### 5.2 编辑 .env 文件

```bash
# 使用你喜欢的编辑器打开 .env
# Windows: notepad .env
# macOS/Linux: nano .env 或 vim .env
```

### 5.3 必填配置项

```bash
# === 服务配置 ===
APP_PORT=8080                    # 后端端口
APP_MODE=debug                   # debug 或 release
LOG_LEVEL=info                   # 日志级别

# === JWT 认证 ===
JWT_SECRET=your-random-secret    # 必须修改！生成随机字符串
JWT_EXPIRE_HOURS=2               # Token 有效期（小时）

# === 数据库 ===
SQLITE_PATH=./data/wxx.db        # SQLite 数据库路径

# === 智谱清言 API（必填）===
ZHIPU_API_KEY=your-zhipu-key     # 从 https://open.bigmodel.cn/ 获取
ZHIPU_BASE_URL=https://open.bigmodel.cn/api/paas/v4/chat/completions
ZHIPU_MODEL=glm-4

# === DeepSeek API（选填）===
DEEPSEEK_API_KEY=your-deepseek-key
DEEPSEEK_BASE_URL=https://api.deepseek.com/chat/completions
DEEPSEEK_MODEL=deepseek-v4-pro

# === 讯飞星火语音 API（选填）===
XFYUN_APP_ID=your-xfyun-app-id
XFYUN_API_KEY=your-xfyun-api-key
XFYUN_API_SECRET=your-xfyun-api-secret
```

### 5.4 生成 JWT_SECRET

```bash
# Windows PowerShell
-join ((1..32) | ForEach-Object { '{0:X}' -f (Get-Random -Max 16) })

# macOS/Linux
openssl rand -hex 32
```

### 5.5 获取 API 密钥

#### 智谱清言（必填）
1. 访问 https://open.bigmodel.cn/
2. 注册/登录账号
3. 进入控制台 → API Keys → 创建 API Key
4. 复制 API Key 填入 `.env`

#### DeepSeek（选填）
1. 访问 https://platform.deepseek.com/
2. 注册/登录账号
3. 进入 API Keys → 创建 API Key
4. 复制 API Key 填入 `.env`

#### 讯飞星火（选填）
1. 访问 https://www.xfyun.cn/
2. 注册/登录账号
3. 创建应用 → 获取 APPID、API Key、API Secret
4. 填入 `.env`

## 6. 后端开发

### 6.1 目录结构

```
server/
├── cmd/
│   ├── server/           # 服务入口
│   │   └── main.go
│   └── migrate/          # 数据库迁移工具
│       └── main.go
├── internal/
│   ├── handler/          # HTTP 处理器
│   ├── service/          # 业务逻辑
│   ├── repository/       # 数据访问
│   ├── model/            # 数据模型
│   ├── middleware/        # 中间件（JWT、RBAC）
│   └── context_engine/   # 知识检索引擎
├── migrations/           # SQL 迁移脚本
└── README.md
```

### 6.2 架构分层规则（强制）

```
handler → service → repository（单向调用）
```

- **handler**：接收 HTTP 请求，调用 service，返回响应
- **service**：业务逻辑，调用 repository 或外部 API
- **repository**：数据访问，操作 SQLite

**禁止**：
- handler 直接调用 repository
- repository 依赖 HTTP 或模型 API

### 6.3 启动开发服务器

```bash
# 方式一：使用 Makefile（推荐）
make dev

# 方式二：直接运行
go run .

# 访问地址
# http://localhost:8080
# 健康检查: http://localhost:8080/api/v1/health
```

### 6.4 数据库迁移

```bash
# 首次运行或更新后执行
make migrate

# 数据库文件位置: ./data/wxx.db
```

### 6.5 代码规范

```bash
# 静态检查
make lint    # 等同于 go vet ./...

# 运行测试
make test    # 等同于 go test ./... -v -cover
```

## 10. 常见问题

### 10.1 Flutter 构建失败

**问题**：`impellerc` 无法处理中文路径

**解决**：使用安全构建命令
```bash
make flutter-build-web-safe    # Web
make flutter-build-apk-safe    # APK
```

### 10.2 Go 编译失败

**问题**：`go-sqlite3` 需要 CGO

**解决**：确保安装了 GCC
```bash
# Windows: 安装 MinGW 或 TDM-GCC
# macOS: xcode-select --install
# Linux: sudo apt install gcc
```

### 10.3 数据库迁移失败

**问题**：`SQLITE_PATH` 目录不存在

**解决**：创建数据目录
```bash
mkdir -p ./data
make migrate
```

### 10.4 Vercel 部署失败

**问题**：前端产物推到了后端项目

**解决**：执行回滚操作
```bash
# 1. 列出 wxx-server 历史
npx vercel ls wxx-server

# 2. 找一个稳定的部署 url
# 3. 切换域名 alias
npx vercel alias set <stable-deployment-url> api.pydaydayup.xyz

# 4. 验证
curl -s https://api.pydaydayup.xyz/health
```

### 10.5 API 请求 401

**问题**：JWT Token 过期或无效

**解决**：
1. 检查 `.env` 中的 `JWT_SECRET` 是否正确
2. 重新登录获取新 Token
3. 检查 Token 是否在 2 小时有效期内

### 10.6 端口被占用

**问题**：`8080` 端口已被占用

**解决**：修改 `.env` 中的 `APP_PORT`
```bash
APP_PORT=8081
```
