## 1. 项目概述

**蔚小芯**是滁州学院计算机学院研发的智慧校园 AI 学工助手，面向全院师生提供智能问答、知识查询、情感预警、语音交互等服务。

### 1.1 核心架构

```

│                  Go/Gin 后端服务                         │
```

## 5. 环境配置

### 5.1 创建 .env 文件

```bash
# 从模板复制
cp .env.example .env
```

### 5.2 编辑 .env 文件

```bash
# 使用你喜欢的编辑器打开 .env
# Windows: notepad .env
# macOS/Linux: nano .env 或 vim .env
```

### 5.3 必填配置项

```bash
# === 服务配置 ===
APP_PORT=8080                    # 后端端口
APP_MODE=debug                   # debug 或 release
LOG_LEVEL=info                   # 日志级别

# === JWT 认证 ===
JWT_SECRET=your-random-secret    # 必须修改！生成随机字符串
JWT_EXPIRE_HOURS=2               # Token 有效期（小时）

# === 数据库 ===
SQLITE_PATH=./data/wxx.db        # SQLite 数据库路径

# === 智谱清言 API（必填）===
ZHIPU_API_KEY=your-zhipu-key     # 从 https://open.bigmodel.cn/ 获取
ZHIPU_BASE_URL=https://open.bigmodel.cn/api/paas/v4/chat/completions
ZHIPU_MODEL=glm-4

# === DeepSeek API（选填）===
DEEPSEEK_API_KEY=your-deepseek-key
DEEPSEEK_BASE_URL=https://api.deepseek.com/chat/completions
DEEPSEEK_MODEL=deepseek-v4-pro

# === 讯飞星火语音 API（选填）===
XFYUN_APP_ID=your-xfyun-app-id
XFYUN_API_KEY=your-xfyun-api-key
XFYUN_API_SECRET=your-xfyun-api-secret
```

### 5.4 生成 JWT_SECRET

```bash
# Windows PowerShell
-join ((1..32) | ForEach-Object { '{0:X}' -f (Get-Random -Max 16) })

# macOS/Linux
openssl rand -hex 32
```

### 5.5 获取 API 密钥

#### 智谱清言（必填）
1. 访问 https://open.bigmodel.cn/
2. 注册/登录账号
3. 进入控制台 → API Keys → 创建 API Key
4. 复制 API Key 填入 `.env`

#### DeepSeek（选填）
1. 访问 https://platform.deepseek.com/
2. 注册/登录账号
3. 进入 API Keys → 创建 API Key
4. 复制 API Key 填入 `.env`

#### 讯飞星火（选填）
1. 访问 https://www.xfyun.cn/
2. 注册/登录账号
3. 创建应用 → 获取 APPID、API Key、API Secret
4. 填入 `.env`

### 6.2 目录结构

```
server/
├── cmd/
│   ├── server/           # 服务入口
│   │   └── main.go
│   └── migrate/          # 数据库迁移工具
│       └── main.go
├── internal/
│   ├── handler/          # HTTP 处理器（接收请求，调用 service）
│   ├── service/          # 业务逻辑（调用 repository 或外部 API）
│   ├── repository/       # 数据访问（操作 SQLite）
│   ├── model/            # 数据模型（实体、DTO）
│   ├── middleware/        # 中间件（JWT、RBAC、审计日志）
│   ├── context_engine/   # 知识检索引擎（FTS5/BM25）
│   ├── agent/            # 智能体编排（Eino）
│   ├── auth/             # 认证授权（JWT、RBAC）
│   ├── llm/              # 大模型客户端（智谱、DeepSeek）
│   └── config/           # 配置加载
├── migrations/           # SQL 迁移脚本（按序号执行）
├── pkg/app/              # 应用初始化（Vercel serverless 入口）
└── embed.go              # 嵌入迁移文件
```

### 6.3 架构分层规则（强制）

```
handler → service → repository（单向调用）
```

- **handler**：接收 HTTP 请求，调用 service，返回响应
- **service**：业务逻辑，调用 repository 或外部 API
- **repository**：数据访问，操作 SQLite

**禁止**：
- handler 直接调用 repository
- repository 依赖 HTTP 或模型 API

### 6.4 数据库迁移机制

迁移文件按文件名排序自动执行，使用 `_migrations` 表记录已执行的迁移：

```
001_init.sql          # 创建所有表
002_test_data.sql     # 测试数据
003_seed_knowledge.sql # 知识种子数据
...
021_add_step_contact_fields.sql  # 添加字段
```

**重要**：新增字段的迁移（如 `ALTER TABLE ADD COLUMN`）必须在使用该字段的 INSERT 语句之前执行。

### 7.3 架构模式

**单向数据流架构**：
```
用户操作 → Page 调用 Provider 方法 → Provider 通过 ApiService 请求后端
         ← Provider.notifyListeners() ← Consumer/watch 重建 UI
```

**关键分层**：
| 层 | 职责 | 约束 |
|---|---|---|
| `pages/` | UI 页面 | 不直接调用 ApiService |
| `providers/` | 业务状态 + 数据获取 | 通过 ApiService 单例发请求 |
| `services/api_service.dart` | Dio 单例，JWT 拦截器 | 全局唯一实例 |
| `config/api_config.dart` | API 路径常量 | 后端地址配置 |
| `models/models.dart` | 数据模型 | `fromJson` 工厂构造 |
| `widgets/` | 可复用组件 | 无业务逻辑 |

**导航结构**：
- 移动端：磨砂玻璃底部 NavigationBar
- 桌面端（>900px）：左侧 NavigationRail
- 路由守卫：未登录 → `/login`，已登录访问 `/login` → `/home`

### 8.5 Vercel 部署（前端 Web）

```bash

make deploy-web

# 仅推送已构建产物（不重新编译）
make deploy-web-prebuilt
```

**部署方式二：手动部署**
```bash
# 1. 构建 Flutter Web
cd frontend
flutter build web --release

# 2. 复制构建产物到 Vercel 目录
cp -rf build/web/* .vercel/output/static/

# 3. 部署到 Vercel

```

**部署方式三：直接使用 vercel.json 配置**
```bash
# 在 frontend 目录下
cd frontend
flutter build web --release
rm -rf deploy && mkdir -p deploy
cp -rf build/web/* deploy/
cp -rf functions deploy/
npx --yes wrangler pages deploy deploy --project-name wxx-agent --branch main
```

**重要提醒**：
- 前端项目：Cloudflare Pages `wxx-agent`（域名：`https://wxx-agent.pages.dev`）
- 后端项目：`wxx-server`（域名：`https://api.pydaydayup.xyz`）
- 前端不要再使用已停用的 `wxx.pydaydayup.xyz` 域名
- Cloudflare Pages 自动部署详见 `docs/蔚小芯前端重新部署.md`

### 8.6 Vercel 部署（后端 Go）

**部署命令**：
```bash
# 在仓库根目录执行（后端使用根目录的 vercel.json）
npx vercel deploy --prod --yes

# 强制重新部署（不使用缓存）
npx vercel deploy --prod --yes --force
```

**部署说明**：
- 后端使用 `api/index.go` 作为 Vercel serverless 入口
- 根目录 `vercel.json` 配置了 Go 构建和路由
- 部署后自动绑定到 `api.pydaydayup.xyz` 域名

**环境变量配置**：
在 Vercel 控制台（https://vercel.com/dashboard）配置以下环境变量：
```
JWT_SECRET=your-random-secret
ZHIPU_API_KEY=your-zhipu-key
ZHIPU_BASE_URL=https://open.bigmodel.cn/api/paas/v4/chat/completions
ZHIPU_MODEL=glm-4
SQLITE_PATH=/tmp/wxx.db
APP_PORT=8080
APP_MODE=release
LOG_LEVEL=info
```

**查看部署状态**：
```bash
# 列出部署历史
npx vercel ls wxx-server

# 检查部署状态
npx vercel inspect <deployment-url>

# 回滚到稳定版本
npx vercel alias set <stable-deployment-url> api.pydaydayup.xyz
```

## 10. 游客系统

### 10.1 概述

游客（Guest）是蔚小芯的**临时访客身份**，无需学号即可注册。游客只能浏览公开信息，所有游客账号需学院书记审核通过后方可正常使用。

### 10.2 数据模型

`users` 表新增 `status` 字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `status` | TEXT | `pending`（待审核）/ `approved`（已通过）/ `rejected`（已拒绝） |

### 10.3 角色权限（RBAC）

在 `server/internal/auth/capabilities.go` 中定义：

```go
// Guest 角色
guest: SelfGuestRead     // 仅可浏览公开信息

// 审核后角色变更
guest → student: SelfRead + ...（完整学生权限）
```

### 10.4 API 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| `POST` | `/api/v1/auth/guest-register` | 游客注册（无需 JWT） |
| `GET` | `/api/v1/admin/guests/pending` | 管理员查看待审核列表 |
| `PUT` | `/api/v1/admin/guests/:id/approve` | 书记审核通过（设为 student 角色） |
| `PUT` | `/api/v1/admin/guests/:id/reject` | 书记审核拒绝 |

**游客注册请求体**：
```json
{
  "username": "guest_xxx",
  "password": "temporary_password"
}
```

**审核响应**：
```json
{
  "code": 200,
  "message": "审核通过",
  "data": {
    "id": 1,
    "username": "guest_xxx",
    "role": "student",
    "status": "approved"
  }
}
```

### 10.5 数据库迁移

| 文件 | 说明 |
|------|------|
| `025_add_user_status.sql` | `users` 表新增 `status` 字段，默认 `approved` |

### 10.6 前端页面

- **登录页**：新增「游客注册」按钮，点击弹出注册对话框
- **首页**：游客可见公开卡片，隐藏需要登录的功能
- **管理端**：新增「游客审核」页面，列出待审核/已处理游客

## 13. 常见问题

### 13.1 Flutter 构建失败

**问题**：`impellerc` 无法处理中文路径

**解决**：使用安全构建命令
```bash
make flutter-build-web-safe    # Web
make flutter-build-apk-safe    # APK
```

### 13.2 Go 编译失败

**问题**：`go-sqlite3` 需要 CGO

**解决**：确保安装了 GCC
```bash
# Windows: 安装 MinGW 或 TDM-GCC
# macOS: xcode-select --install
# Linux: sudo apt install gcc
```

### 13.3 数据库迁移失败

**问题**：`SQLITE_PATH` 目录不存在

**解决**：创建数据目录
```bash
mkdir -p ./data
make migrate
```

### 13.4 Vercel 部署失败

**问题**：前端产物推到了后端项目

**解决**：执行回滚操作
```bash
# 1. 列出 wxx-server 历史
npx vercel ls wxx-server

# 2. 找一个稳定的部署 url（状态为 ● Ready，构建时间约 30s-1min）
# 3. 切换域名 alias
npx vercel alias set <stable-deployment-url> api.pydaydayup.xyz

# 4. 验证
curl -s https://api.pydaydayup.xyz/health
```

### 13.5 Vercel 后端部署后返回 500

**问题**：后端部署成功但接口返回 500 错误

**可能原因**：
1. 数据库迁移失败（字段不匹配）
2. 环境变量未配置
3. 初始化代码错误

**排查步骤**：
```bash
# 1. 查看具体错误信息
curl -s https://api.pydaydayup.xyz/health

# 2. 检查部署日志
npx vercel logs <deployment-url>

# 3. 强制重新部署
npx vercel deploy --prod --yes --force
```

**常见迁移错误**：
- `table xxx has no column named yyy`：INSERT 语句使用了未添加的字段
- `all VALUES must have the same number of terms`：INSERT 语句字段数量不匹配

### 13.6 Vercel 后端环境变量配置

**在 Vercel 控制台配置**：
1. 登录 https://vercel.com/dashboard
2. 进入 `wxx-server` 项目
3. Settings → Environment Variables
4. 添加以下变量：

```
JWT_SECRET=your-random-secret
ZHIPU_API_KEY=your-zhipu-key
ZHIPU_BASE_URL=https://open.bigmodel.cn/api/paas/v4/chat/completions
ZHIPU_MODEL=glm-4
SQLITE_PATH=/tmp/wxx.db
APP_PORT=8080
APP_MODE=release
LOG_LEVEL=info
```

5. 保存后重新部署

### 13.7 API 请求 401

**问题**：JWT Token 过期或无效

**解决**：
1. 检查 `.env` 中的 `JWT_SECRET` 是否正确
2. 重新登录获取新 Token
3. 检查 Token 是否在 2 小时有效期内

### 13.8 端口被占用

**问题**：`8080` 端口已被占用

**解决**：修改 `.env` 中的 `APP_PORT`
```bash
APP_PORT=8081
```
