# 蔚小芯 — 角色功能规划

> **版本**: v4.0  
> **日期**: 2026-05-14  
> **定位**: 信息学院智慧校园 AI 学工助手（蔚小芯）全部角色功能梳理与重新规划  
> **核心理念**: 从"信息查询工具"升级为"AI 原生教育智能体"，每个角色拥有差异化、创新性、不可替代的特色功能  
> **学生功能**: 40 项，覆盖「入学—在校—离校—就业」全生命周期，融合「政治·思想·心理·专业」四位一体育人体系，构建「每日陪伴→学情洞察→成长规划→能力发展→校园生活→成长激励」六层应用粘性架构  
> **辅导员功能**: 21 项，形成「每日关注→风险预警→谈心谈话→育人档案→沟通自动化」五层增效体系  
> **教师功能**: 18 项，构建「课前准备→课堂互动→课后反馈→学情洞察→育人协同」完整教学闭环  
> **教辅功能**: 12 项，聚焦「排课→考试→毕业」三大刚需场景的 AI 流程自动化  
> **管理员功能**: 补强教师效能分析、课程质量评估、校级学情总览、用户行为分析等 AI 数据决策能力

## 二、现有功能问题分析

### 2.1 核心问题

| 问题类别 | 具体表现 | 影响 |
|----------|----------|------|
| **角色功能雷同** | 学生、学生会、辅导员、管理员的问答/浏览/语音功能几乎一致，仅数据范围不同 | 角色差异化价值为零，用户无感知切换角色的必要 |
| **功能缺乏实际意义** | 情感预警仅"查看告警列表+标记已处理"，无预测、无归因、无行动建议 | 辅导员仍需人工判断，AI 价值未体现 |
| **无创新特色功能** | 所有功能均为传统 CRUD + 问答，未利用 AI 能力创造新体验 | 与普通信息查询系统无本质区别 |
| **被动服务为主** | 学生需主动提问，系统缺乏主动引导、成长陪伴、预警推送 | 用户粘性低，使用频次依赖痛点驱动 |
| **数据价值未挖掘** | 积累的问答/行为/情感数据仅做简单统计，无深度分析与可视化 | 管理者决策仍凭经验，数据驱动未落地 |
| **教育属性薄弱** | 无学习路径规划、无能力评估、无成长追踪、无引导教育 | "学工助手"退化为"信息查询器" |

### 2.2 根因分析

1. **设计思路停留在"信息检索"层面**：将 AI 定位为"更聪明的搜索引擎"，而非"教育智能体"
2. **角色设计以权限范围区分，而非以场景和价值区分**：六级角色的差异仅在"看多少数据"，而非"做什么不同的事"
3. **缺乏 AI 原生思维**：未从数字人、数字孪生、智能分析、引导教育等 AI 时代原生应用角度重新定义功能

## 三、重新规划——各角色特色功能

> 设计原则：
> 1. **每个角色至少 2 项独占特色功能**，其他角色无法替代
> 2. **AI 原生**：功能以 AI 能力为核心，而非 AI 辅助传统功能
> 3. **主动服务**：从"用户问→系统答"升级为"系统感知→主动引导"
> 4. **数据驱动**：全量数据分析和可视化贯穿所有角色
> 5. **教育为本**：功能服务于"入学—在校—毕业"全生命周期教育目标

### 3.1 学生（student）— AI 原生成长伙伴

> 学生是蔚小芯的第一服务对象。功能设计遵循「每日陪伴 → 学情洞察 → 成长规划 → 能力发展 → 校园生活 → 成长激励」六层递进，
> 覆盖「入学—在校—离校—就业」全生命周期，融合政治教育、思想引领、心理健康、专业教学四位一体育人体系，
> 每日学情数据驱动、性格洞察适配、AI学伴互动、积分成就激励四重粘性机制确保用户持续活跃。

## 四、AI 原生特色功能详解

### 4.1 数字人导师（学生独占）

**核心价值**：从"文字问答"升级为"拟人化对话陪伴"，让 AI 有温度、有形象、有记忆。

| 维度 | 说明 |
|------|------|
| 技术实现 | LLM（智谱/DeepSeek）+ TTS（讯飞）+ 2D 数字人渲染（Live2D 或 Web 端 CSS 动画） |
| 交互方式 | 语音对话为主，文字对话为辅；数字人形象实时口型同步+表情反馈 |
| 个性化 | 支持选择导师风格（温和型/严格型/幽默型）；记住学生历史对话与偏好 |
| 教育场景 | 入学适应期陪伴、考前心理疏导、职业规划对话、日常学业答疑 |
| 数据来源 | 学生画像 + 知识库 + 对话历史 + 培养方案 |
| 隐私保护 | 对话内容脱敏后存储；情感分析仅在学生授权后启用；辅导员仅看摘要不看原文 |

**MVP 范围**：P1 实现 2D 静态形象 + 语音对话 + 3 种风格切换；P2 升级为动态形象 + 长期记忆 + 主动关怀。

### 4.2 个人数字孪生（学生独占）

**核心价值**：让每个学生拥有一个"数字化的自己"，实时映射多维状态，让成长可量化、可追踪、可对比。

| 维度 | 说明 |
|------|------|
| 技术实现 | 多维数据聚合 + 雷达图/热力图可视化 + AI 状态解读 |
| 数据维度 | 学业进度（学分/绩点/课程完成度）、能力雷达（专业/实践/创新/沟通/领导力）、情感状态（趋势+当前）、社交活跃度（活动参与/社团/志愿服务）、成长轨迹（时间线+里程碑） |
| 核心交互 | "现在的我" vs "理想的我"对比；拖动"理想值"查看差距与 AI 建议；时间轴回溯历史状态 |
| AI 能力 | 自动识别短板并推荐提升路径；预测未来状态趋势；异常波动自动提醒 |
| 可视化 | 雷达图（能力）、热力图（时间分配）、趋势线（情感/学业）、里程碑时间线 |

**MVP 范围**：P1 实现五维雷达图 + AI 状态解读 + 差距分析；P2 增加趋势预测 + 里程碑追踪 + 主动提醒。

### 4.3 AI 成长路径规划（学生独占）

**核心价值**：从"学生问什么答什么"升级为"AI 主动规划成长路径"，实现真正的引导教育。

| 维度 | 说明 |
|------|------|
| 技术实现 | 知识图谱（培养方案+就业要求）+ 约束求解 + LLM 生成 |
| 输入 | 学生画像 + 专业培养方案 + 就业市场数据 + 历史优秀路径 |
| 输出 | 学期里程碑清单 + 能力提升建议 + 推荐活动/课程/竞赛 + 时间节点提醒 |
| 交互 | 学生可调整目标（考研/就业/创业），AI 实时重新规划路径；完成里程碑自动打卡 |
| 动态调整 | 学业/行为数据变化时，AI 自动调整路径建议 |

**MVP 范围**：P1 实现基于培养方案的静态路径生成 + 里程碑打卡；P2 增加动态调整 + 就业数据驱动 + 路径模拟。

### 4.4 学生数字孪生看板（辅导员独占）

**核心价值**：从"逐个查看告警"升级为"一屏感知全局"，让辅导员从信息海洋中解放。

| 维度 | 说明 |
|------|------|
| 技术实现 | 聚合学生数字孪生数据 + 热力图/散点图 + 异常检测算法 |
| 核心视图 | 全班/全年级学生状态热力图（绿/黄/红）；点击个体下钻到个人数字孪生；异常学生自动排序高亮 |
| AI 能力 | 自动识别"群体性异常"（如某门课后多人情感下降）；生成班级健康度周报 |
| 预警升级 | 不再仅依赖情感分析，综合学业/出勤/活动/社交多维指标预警 |

**MVP 范围**：P1 实现全班状态热力图 + 个体下钻 + 异常排序；P2 增加群体异常检测 + AI 周报。

### 4.5 AI 预测性预警（辅导员独占）

**核心价值**：从"事后告警"升级为"事前预测"，让辅导员有时间提前干预。

| 维度 | 说明 |
|------|------|
| 技术实现 | 时序模型 + 行为模式识别 + LLM 归因生成 |
| 预测维度 | 学业下滑风险、心理波动风险、社交退缩风险、退学/休学风险 |
| 预测窗口 | 未来 2-4 周 |
| 输出 | 风险等级 + 影响因素排序 + 建议干预时间窗口 + 历史类似案例 |
| 准确率目标 | 高风险召回率 ≥ 80%（与现有情感预警一致），误报率 ≤ 15% |

**MVP 范围**：P1 实现基于规则+统计的预测模型；P2 升级为 LLM 增强的归因分析。

### 4.6 AI 干预方案生成（辅导员独占）

**核心价值**：从"辅导员凭经验决策"升级为"AI 生成方案+辅导员审核调整"，降低专业门槛。

| 交互 | 辅导员可编辑/增删建议项；标记采纳/未采纳；记录实际干预效果用于模型优化 |

**MVP 范围**：P1 实现模板化方案生成 + 编辑采纳；P2 增加案例库检索 + 效果反馈闭环。

### 4.7 AI 活动策划助手（学生会独占）

**核心价值**：从"人工写策划案"升级为"AI 创作+人工审核"，释放学生会创造力。

| 维度 | 说明 |

**MVP 范围**：P1 实现文本策划案生成 + 宣传文案生成；P2 增加海报图片生成 + 预算优化 + 风险评估。

### 4.8 学院数字孪生大屏（学院管理员独占）

**核心价值**：从"看报表"升级为"实时全景感知"，让管理者一眼掌握全院动态。

**MVP 范围**：P1 实现核心可视化大屏 + 静态数据展示；P2 增加自然语言查询 + 实时推送 + AI 解读。

### 4.9 AI 全量数据分析与可视化（学院/学校管理员）

### 4.13 AI 课程地图（学生独占）
