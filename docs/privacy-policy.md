# 蔚小芯隐私政策

> 生效日期：2026-05-14  
> 适用范围：计算机学院蔚小芯 AI 学工助手

## 一、信息收集

蔚小芯仅收集提供学工服务所必需的最少信息：

| 信息类型 | 用途 | 存储期限 |
|----------|------|----------|
| 用户名/学工号 | 身份认证与角色识别 | 账号存续期间 |
| 角色与归属（学院/班级） | 权限控制与内容过滤 | 账号存续期间 |
| 问答记录 | 改进服务质量与审计 | 不超过 1 学年 |
| 语音录音（如使用语音功能） | 语音转文本后即删除 | 处理后立即删除 |

## 二、信息使用

- 仅用于提供学工咨询、流程指引、情感预警等服务
- 不会用于商业广告、用户画像营销或第三方共享
- 脱敏处理后的统计数据用于服务质量分析

## 三、信息存储与保护

- 所有数据存储于境内学院服务器
- 传输层使用 HTTPS 加密
- 发送至第三方大模型 API 的问题文本自动脱敏（学号/手机号/身份证号替换为掩码）

## 四、用户权利

- 可随时查看本人问答历史
- 可申请删除本人账号及关联数据
- 可撤回隐私授权（撤回后部分功能受限）

## 五、情感分析特别说明

情感分析功能需单独授权。分析结果仅用于：
- 识别需关怀的高风险学生
- 向辅导员发送预警通知（仅管辖范围内的学生）

情感分析原始记录不向第三方披露。

## 六、联系方式

- 计算机学院学工办公室
- 系统管理员：见智能体管理中心
