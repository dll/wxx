## 一、背景与目标

**现状（2026-08-14 核查）**
- Flutter 前端 `frontend/`（v0.0.27+27）已支持 Web / Android / iOS；现有 CI 产出 Web（Cloudflare Pages）、Go 后端、Android APK。
- `build-mobile.yml`（iOS + HarmonyOS）**已提交但从未运行**（`gh run list` 无记录）。
- iOS 工程存在（bundle id `com.wxx.wxxApp`），未配置 `DEVELOPMENT_TEAM`，`ExportOptions.plist` 为占位符，从未构建过。
- 鸿蒙工程已落地 `frontend/harmonyos/`（ArkTS WebView 壳，bundleName `com.wxx.weixiaoxin`，hvigor modelVersion 5.0.0），本机 DevEco 曾构建成功。
- **签名凭据未配置**：仓库 Secrets 仅含部署相关（BAIDU/CLOUDFLARE/SERVER/SSH/VERCEL），**无 Apple 证书、无 ASC API Key、无华为 AGC 证书**。

**目标**
在 GitHub Actions 上实际构建 **iOS** 与 **鸿蒙** 两种移动应用制品并发布，与 Web/Android 版本号同步。

## 二、本期可交付 / 不可交付

**可交付（无凭据即可）**
1. iOS：`flutter build ios --release --no-codesign`，产出 **未签名 `.app.zip`**（Actions artifact + GitHub Release 资产）。
2. 鸿蒙：`hvigorw assembleHap -p buildMode=debug`，产出 **debug 未签名 `.hap`**（Actions artifact + GitHub Release 资产）。
3. 验证 workflow 全链路可跑通；产物挂 Release `v0.0.27`。

**不可交付（凭据阻塞）**
- ❌ 签名 `.ipa` / 上传 TestFlight（需 Apple 证书 + ASC API Key）。
- ❌ 签名 HAP 真机安装 / 上架 AGC（需华为发布证书 + Profile）。
- ❌ iOS 真机验证（未签名产物仅限模拟器/存档）。

## 三、执行步骤（审核通过后）

1. **准备**
   - 对齐版本号：鸿蒙 `app.json5` versionName=1.0.0 → 改为 `0.0.27`，versionCode=1000000 → 按 `27`（或 `10000027`）对齐 Flutter `0.0.27+27`。
   - 确认 `ExportOptions.plist` 保持占位（本期不签名，不阻塞）。

2. **触发构建**
   - GitHub Actions → **Build Mobile Apps** → Run workflow（`ios_target=unsigned`，`harmonyos_target=unsigned`）。
   - 两个 Job：`build-ios`（macos-15，Flutter 3.22.0）、`build-harmonyos`（ubuntu，JDK17+Node20+HarmonyOS SDK）。

3. **发布**
   - 若 CI 成功：`gh release upload v0.0.27 <ipa-app.zip> <hap>`（或从 Actions artifact 下载后上传）。
   - 若鸿蒙 SDK 下载失败（已知风险，海外 runner 从华为 CDN 下载可能受限）：报告并更新 workflow 中 SDK 下载地址/降级容错，重跑。

4. **文档与提交**
   - 更新 `docs/移动应用构建与发布.md`（产物/实测状态）。
   - 提交计划文档 + 版本对齐变更 + workflow 修正（如有）。
