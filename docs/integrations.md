# 校外系统对接 — 规范注意（摘录）

> 完整流程与图示见同目录 **`蔚小芯智能体.md`** §6.1～§6.3、§6.5。

## 共性要求

- **经授权的只读 / 代理访问** 为主；写操作与数据范围以校方批复为准。
- **SSO / JWT**：门户统一身份与刷新策略与后端 RBAC 对齐。
- **合规**：HTTPS、服务间 Token、审计日志、限流与告警阈值。

## 学工 / 一表通

- 网关聚合、字段映射、定时拉取与缓存合并：见总纲 §6.1、§6.2。  
- P0 至少一条真实只读代理；若延期采用 Mock + Demo Scope（总纲 §7）。

## 多端入口

- Web、独立 App、微信小程序（Flutter 不直接产小程序，需单独轻量端）、快应用/鸿蒙分期：见 §6.5.3、§6.5.4。
