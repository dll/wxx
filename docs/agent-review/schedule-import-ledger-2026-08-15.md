## 三、补齐操作
A 类补名单（学号/姓名/班级三列 xlsx 放 data/）后重跑：
```
python server/scripts/import_schedules.py --db server/data/wxx.db --students 需补班级列表
```
脚本自动：建学生账号（密码=学号）→ 解析对应班级课表 → 展开到每位学生。
