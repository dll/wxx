## 四、补齐所需（供你准备）

要导入 A 类 21 个班，需提供这些班的**学生名单文件**（含 学号/姓名/班级 三列即可），放入 `data/` 后重跑：
```
python server/scripts/import_schedules.py --db server/data/wxx.db --students 大数据23,计科231,...（需补的班级）
```
脚本会自动：建学生账号（密码=学号）→ 解析对应班级课表 → 展开到每位学生。
