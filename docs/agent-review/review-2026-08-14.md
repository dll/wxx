## 一、体验总览

一句话：**蔚小芯不是"一个软件"，而是新生入学、在校、离校三年一条龙的 AI 学伴——方向完全正确，大一新生"愿意用"的骨架已经在了；但"愿意天天用、用得爽"还需要在"第一次上手"和"真正解决小事"两个环节再打磨。**

以大一新生视角，第一天上手的真实心路：我考上大学 → 同学/辅导员发来一个网址 → 我打开 → 要用学号登录（初始密码也是学号）→ 强制改密 → 看到首页 → 我会先试什么？**先问它问题，因为我是来"找人问事"的。**

### 亮点功能清单（新生会真心喜欢 ✅）

| 功能 | 新生视角为什么喜欢 |
|------|------------------|
| **智能问答（问芯）** | 我最需要的就是"不懂就问、马上有答案"，还有来源可查、不怕它瞎编 |
| **5 个智能体 + 默认协同** | "拿不准选默认"这个设计对小白极度友好，选错也能答 |
| **新生指南（Freshmen Guide）** | 报到 11 步 + 专升本说明 + 学生手册要点，入学最早需要的就是它 |
| **年级主题横幅**（迎新青绿） | 一进来有归属感，"这是给我这届的" |
| **办事直达（分步指引+材料+地点）** | 请假/入党/报销这种"不知道去哪办、带什么"恰恰是我最慌的 |
| **热门话题** | 我不用搜索就知道大家在关心什么，避免信息过载 |
| **问题反馈（一键截屏）** | 遇到问题能随手上报，不用找渠道 |
| **学习打卡/积分** | 有即时正反馈，能坚持用（但见痛点 3） |
| **心理疏导智能体** | 有情绪问题有地方说，且危机词自动转介——新生离家的安全感 |

## 二、痛点清单（按影响排序）

### [高] 1. "第一次打开不知道能干什么" —— 缺一个新生"上手引导"

- **新生视角**：我登录进来看到一堆卡片（今日速览/快捷功能/新生指南/办事/服务/我的），但我其实只想知道"我现在该干嘛"。
- **现状/根因**：学生手册有完整图文引导，但**应用内没有**面向新生的引导层（onboarding / 新手任务 / 引导气泡）。首页信息密度高，第一次使用容易"不知道点哪"。
- **建议改进**：新增**新生引导**——首次登录强制改密后弹一次极简引导（3 步：① 问芯=问问题 ② 办事=办手续 ③ 报到=走流程），并给一个"新生入学待办清单"（报到→领卡→体检→军训→选课），每完成一项打勾，天然形成"每天打开的理由"。
- **是否已实现**：未实现。`freshman_plan_page.dart` 存在但为死路由/纯文本（见《全面分析》P1-9）。

### [高] 2. "问的问题它答不上来" —— 知识兜底率与"不确定"体验

- **新生视角**：我兴冲冲问"我们班什么时候领军训服"，结果它说"不确定，请联系辅导员"。问三次这样我就懒得用了。
- **现状/根因**：知识库仅 50 条级，`ownerScope/roleScope` 过滤 + 低置信清空 sources 触发兜底（符合"不编造"硬约束，但对新生体验是挫败）。《全面分析 P1-13》指出知识规模不足 + 无治理运营循环。
- **建议改进**：① 上线前按 8 业务域补齐 Top 高频新生问题（≥200 条标注集）；② 兜底回复里**不要只说"不确定"**，要给出**可执行动作**（"建议问 辅导员X / 打 Y 电话 / 去 Z 大厅"）——把"答不上"变成"告诉你去哪能问到"；③ 把兜底问题自动进反馈池，运营周会处理。
- **是否已实现**：部分。渠道指引有雏形，但"可执行动作式兜底"不系统。

### [高] 3. "积分/打卡了却没感觉" —— 激励体系对新生不够直观

- **新生视角**：我打了卡，积分数字变了，但我不知道积分能干嘛，也没有成就感（没徽章弹窗、没排行）。
- **现状/根因**：《全面分析 P2/阶段二》已建 `student_points`/`qa_posts`/`talk_records` 真实表，`Achievements` 已接真实积分（打卡+5/发帖+10/回答+15），但**积分用途单一**，缺少"成就解锁动效"和"排行"激励。
- **建议改进**：① 打卡/发帖成功时给**即时徽章动效 + 进度条**（"距下一徽章还差 3 次"）；② 增加"本班学习活跃周榜"；③ 积分可兑换**实用权益**（打印券、自习室时段、活动优先报名）——新生很吃这一套。
- **是否已实现**：积分底层已落地，激励展示层待增强。

### [中] 4. 校园导航"能看地图，但不知道我要去的地方在哪"

- **新生视角**：我办手续要去"一站式服务大厅"，地图上标的节点可能和实际有偏差，而且我不知道从宿舍怎么走。
- **现状/根因**：存在校园导航 + 报到节点坐标管理（管理员拖拽校正），但缺少"从 A 到 B 的路线指引/距离提示"。
- **建议改进**：节点卡片加"相对位置描述"（"在食堂西侧 100 米"）+ 常用地点一键"设为起点导航"。
- **是否已实现**：坐标管理已实现，路线/相对指引待补。

### [中] 5. AI 额度对新生是"隐性门槛"

- **新生视角**：我用得好好的突然提示"本月 100,000 tokens 用完"，还要我去绑定自己的 API Key——我一个新生哪知道什么是 API Key、去哪申请？
- **现状/根因**：额度用完需等重置或绑 Key（学生手册 2.8）。对小白，绑 Key 门槛太高。
- **建议改进**：额度接近用完时**提前推送提醒**（"本月还剩 X，下月 1 日重置"），并在"绑定 API Key"处给**图文教程 + 入门引导**（第一次接触 API 的新生）。默认额度对新生可适当放宽，或用"基础问答不计费、深度生成计费"策略。
- **是否已实现**：额度查看和绑 Key 有，新手引导化待补。

### [中] 6. "我是新生，但系统不知道我是新生" —— 年级感知可再进一步

- **新生视角**：首页有"迎新"主题色，但内容上我想看到"我这届专属"的东西（军训安排、选课时间、新生体检）。
- **现状/根因**：年级主题是配色层面；`freshmen_guide` 数据有（9/13 报到），但"按入学年份动态聚类"的个性化内容不强。
- **建议改进**：把报到、军训、选课、体检等**按 2026 级时间线**做成"新生时间轴"卡片放首页（今天该做什么），真正做到"越用越懂你"。
- **是否已实现**：新生指南数据有，时间轴式首页待补。

### [低] 7. 导出功能对新生不是刚需，但"收藏"很刚需

- **新生视角**：PDF/Word 导出我用不上；但我问到"入党流程"，我**想收藏**下次再看。收藏入口在吗？
- **现状/根因**：存在 `bookmarks/` 页面 + AnswerCard 有收藏按钮，但新生未必找得到"我的收藏"在哪。
- **建议改进**：个人中心加"我的收藏"显眼入口；支持"收藏夹分组"（入学/学业/生活）。
- **是否已实现**：书签有，入口与分组待增强。

## 三、新生最想要、当前缺失的功能（补齐清单 ➕）

1. **应用内新手引导（onboarding）** —— 首次登录 3 步引导 + 入学待办清单（最高优先）。
2. **"答不上→告诉你去哪办"式兜底** —— 把兜底从挫败变指引。
3. **新生专属"时间轴/今天该做啥"首页卡** —— 按入学日期动态推送报到/体检/选课/军训节点。
4. **可执行的办事查询** —— 办事页面除了"指引"，加"我办到哪一步了"状态（对接学工/申请状态），新生最怕"办到一半不知道进展"。
5. **语音输入广覆盖** —— 手册只提手机端语音导航；新生打字慢/懒得打，Web 端也建议开放语音提问。
6. **"问室友/问学长"的同学习惯社区** —— 问答广场已落地（`qa_plaza_page`），建议加"按专业/班级筛选"，让新生能问"我们专业大二都选什么课"这种同侪问题。

## 四、优化建议（可用但别扭 ⚠️）

| 现状 | 新生体验问题 | 优化建议 |
|------|------------|---------|
| 底部 5 个导航（首页/问芯/办事/服务/我的） | "服务"和"办事"容易混淆 | 明确"办事=办手续流程"，"服务=学习生活工具"，或合并 |
| 初始密码=学号、强制改密 | 安全好评，但可能因改密失败卡在登录 | 改密失败给出明确提示 + "忘记密码"一步直达辅导员重置 |
| 单选智能体 vs 默认协同 | 新生常纠结"该选哪个" | 默认就很好，别让选择成为负担；选择器加"不知道选哪个→用默认"提示 |
| AI 额度位置深（我的→AI 模型配置） | 新手难找到、难理解 | 首页或用量提醒气泡引导 |
