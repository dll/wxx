# 书记 × 蔚小芯：党建育人闭环蓝图（2026-08-15）

> 业务模型：书记以蔚小芯为抓手，协同教师/教辅教育好学生（学生为主角）；教师教辅承担线下线上实际活动；**所有育人数据最终汇流到书记**，形成"书记部署 → 教师教辅执行 → 学生成长 → 绩效回流书记"的闭环。

## 一、书记党建职能 对应的系统数据模型（已建）

书记职能描述：入党教育、上党课、发展学生、做入党介绍人、学生/教师党员发展、开展入党积极分子活动。

系统已有表（`024_student_features.sql`）**字段恰好对上**：

| 书记职能 | 系统字段/表 |
|---|---|
| 发展学生党员 | `party_progress.current_stage` 五阶段：applicant→activist→development→probation→member |
| 做入党介绍人 | `party_progress.party_member_id`（入党介绍人） |
| 支部书记 | `party_progress.branch_secretary` |
| 各阶段推进 | `apply_date/activator_date/development_date/probation_start/conversion_date` |
| 上党课/理论学习 | `party_study_records`（theory/practice/meeting/volunteer + duration 时长 + certificate） |
| 入党教育内容 | `party_stages`（阶段说明/所需材料）+ 知识库"入党流程与要求" |

**结论：党建育人数据底座已就位，字段与书记职能一一对应。**

## 二、现状缺口（已核实）

1. **书记无侧入口**：全部 party 能力是 `SelfParty*`（学生自报）。书记/学院书记（school_admin/college_admin）**看不到任何入党数据**。
2. **统计逻辑已存在但没接线到书记**：`GetPartyStats`（总数/学习记录/时长/阶段分布）挂在 `party/stats`（`SelfPartyRead`）——书记没法用，且维度不够（缺按学院/介绍人/支部书记/活动频次）。
3. **教师/教辅协同缺失**：`party_progress` 只学生填 + 介绍人字段，**无教师/教辅参与记录**（谁带了党课、谁组织活动、谁做思想汇报谈话）。
4. **汇流链路断**：教师教辅的育人工作（谈心/后勤/排课/答疑/党建）各自在个人画像，**未在书记侧汇总成"协同育人总览"**。

## 三、闭环设计（规划 → 待实现）

### 汇流模型
```
书记（部署/审批/看板）
   │
   ├── 蔚小芯（抓手/记录/聚合/智能分析）
   │     ├── 党课/活动登记（教师教辅操作，记录"谁组织、谁参加、时长"）
   │     ├── 入党组织发展（介绍人/支部书记推进，各阶段时间点）
   │     └── 育人动作汇总（谈心/后勤/排课/答疑 按学院聚合）
   │
   ├── 教师/教辅（实际执行者：线下线上活动 + 记录）
   └── 学生（主角：参与、学习、成长五维画像）
结果 → 全部回流书记看板
```

### 要新增的书记侧报告（3 块，均基于已有真实表）
1. **党建育人总览**：入党漏斗（各阶段人数）、按学院分布、上党课人次/时长、积极分子活动数——复用 `GetPartyStats` + 扩展按学院，接到 school/college admin。
2. **协同育人总览**：书记视角看"教师教辅为育人做了多少"——聚合 talk_records、party_study_records、facility_records、audit_logs 按学院/角色汇总。
3. **学生成长闭环**：学生五维画像快照趋势 + 参与活动/学习记录，让书记看到"育人努力 → 学生变化"的证据链。

### 要新增的登记动作（教师/教辅侧）
- 党课/积极分子活动登记（谁组织、谁参加、时长、证明材料）→ 落 party_study_records（补 created_by 维度）
- 入党组织发展推进（介绍人确认、阶段更新带教师/书记操作痕迹）

## 四、诚实边界（不瞎编红线）
- 复用已有真实表（party_progress/party_study_records/talk_records/audit_logs），**不新造虚构绩效**。
- 学生侧自报的 party_progress 目前是"意向登记"性质；书记看板的"党员数字"应标注 `data_source`（real/self-reported），**不把自报当组织确认**。
- 归因类结论（"某干预带来学生改变"）不做因果断言，只做趋势/相关性描述。
