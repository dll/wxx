# 课表源数据分析与分角色导入方案（194教师 + 46班级）

- 日期：2026-08-15
- 源数据：`data/194个教师课表.zip`（194 个《工号-姓名》课表.xlsx）、`data/46个班级课表.zip`（46 个《班级》课表.xlsx）
- 原则：准确性第一；先分析数据依赖，再定角色与导入路径

---

## 一、数据结构（实测解析）

### 教师课表《工号-姓名》课表.xlsx
- Sheet「课表」：第1行学期；第2行 节次/周一~周日；第3-4行 1-2节/3-4节；第5行午间；第6-8行 5-6/7-8及晚间；第9-10行 9-10/11-12节
- 单元格富信息：`课程名●周次●节次●上课班级(班组人数)●教师●地点`，如 `数字逻辑●1-16周[1-2节]○计科251○董再鹏,皮新语◇YF4206`
- **含：课程、周次、节次、上课班级、任课教师、上课地点**（信息最全）

### 班级课表《班级》课表.xlsx
- 同构表格；单元格为 `☆课程名●周次`，如 `☆网络空间安全导论●5-9,`
- **仅含课程名 + 周次；缺上课地点/教师**
- 班级覆盖 21级~26级（计科/网安/软件/大数据/空间/网工，本科+研究生）

### 周次格式（多样，需解析）
- `1-16`、`2-5,8`、`5-17单周`、`1-17周`、`2-4单周` 等（含"单周/双周"、逗号分段）

---

## 二、账号映射依赖（关键）

`course_schedules` 按 **user_id** 存课表。要把课表"导入到人"，需建立：
- **教师课表**：`《工号-姓名》` → users(username=工号, role=teacher) → user_id
- **班级课表**：`《班级》` → 学生名单（`计科251学生名单.xlsx`、`2026级新生录取数据.xlsx` 提供 学号/姓名/班级）→ users(username=学号, role=student, class_name=班级) → 每个学生 user_id

**现状 users 表**：仅 1 个 teacher（teacher1）、17 个测试 student。**194 教师、46 班学生大多未建账号**。

---

## 三、合理角色分配（回答"哪个角色导入"）

| 数据 | 合理导入角色 | 归属 | 用途 |
|------|-------------|------|------|
| **教师课表(194)** | 教务员 / 管理员 | 教师 user_id（username=工号） | 教师端"今日课程/备课" |
| **班级课表(46)** | 班委(student_union) / 教辅(assistant) / 辅导员 | 班级内每个学生 user_id（username=学号） | 学生端"首页今日课表/学习计划" |
| 新生26级课表 | **暂不导入**（用户明确新生26级暂时未有；且新生账号可能未就绪） | - | - |

角色权限已具备：`/admin/schedules/import`（BatchScheduleImport，学生会/教辅/辅导员/管理员）+ `/student/schedule/import`（学生本人）。

## 四、实现前置（决定能否"导入所有"）
1. **需先按名单建账号**：194 教师（from 课表文件名工号+姓名）、46 班学生（from 计科251/252名单 + 2026新生录取数据 361人，按班级过滤）
2. 班级课表 **缺地点**（course_schedules.location 留空即可，不编造）；教师课表含地点可填
3. 课表导入工具：需解析 zip→xlsx→周次/节次/星期→生成 ScheduleRow(user_id=对应人, semester_code=学期, weekday, start_period, end_period, weeks_pattern, location, teacher, course_name)

## 五、待确认决策点（重要，避免导错）
1. **是否先建账号再导入所有课表**？这是"导入所有教师和班级"的前提（当前账号不足）。若先建：会新增 194 教师 + 数百学生账号（影响现有测试环境），需你确认。
2. **26 级是否确认不导入**？（zip 里有 26 级班级课表文件，但你明确新生未有——按不导入处理）
3. **教师课表归属**：当前仅 teacher1 一个教师账号。是新建 194 个教师账号导入全部，还是仅演示导入现有 teacher1？（若演示，只能导 1 位教师的课）
4. 班级课表缺地点：是否接受 location 留空（不编造）？

> 结论：**角色分配清晰**（教师课表→教务/管理员；班级课表→班委/教辅/辅导员；26级不导）。但"所有教师和班级"需**先建账号**（依赖名单），且**班级课表无地点**。确认以上 4 点后即可实现导入工具与批量入库。
