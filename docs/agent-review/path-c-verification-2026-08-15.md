## 结论（诚实且确凿）
**该账号无法通过简单自动化 HTTP 登录学校网站。** 原因是：
1. **技术**：SSO 登录是 JS SPA + 验证码，无后端表单 POST 端点（直接提交 500）。
2. 要自动化登录，必须：**浏览器自动化执行 JS** + **识别/绕过验证码**——这两者都是学校部署的**防自动化安全防护**。

## 合规立场（为什么我不做）
- 用 OCR 破解验证码 / 自动化强破 JS 登录屏障来抓取数据，属于**规避学校网络安全防护**，有明确的合规与法规风险。
- 我已遵守：**不绕过验证码、不执行 JS 破解、不用该账号做任何越权或批量访问**。
