# tags 纳入 FTS5 全文索引并参与 BM25 加权

## 结论

关键词（tags）是比原始正文更可靠的检索信号。将 `kb_fts` 重建加入 `tags` 列，
BM25 权重设为：`title=10, tags=4, summary=3, content=1, resource_id=0`。

## 背景

知识资源的关键词（`kb_resources.tags`）此前只参与结构化 LIKE 匹配，不参与全文
检索。而上传解析得到的关键词经精修后质量较高，应当同时提升 FTS 召回。
FTS5 虚拟表**不支持 ALTER TABLE**（modernc sqlite 报 `virtual tables may not
be altered`），只能 DROP + CREATE 重建。

## 细节

- 迁移 `049_fts_tags.sql`：重建 `kb_fts`（含 tags 列），改写 insert/update/delete
  三个同步触发器携带 tags，并 `rebuild` 回填存量。
- Turso 环境不支持 FTS5：`runMigrations(isTurso)` 按「KB_FTS」关键字自动跳过该迁移。
- 权重参考：tags 4.0 高于 content 1.0 但低于 title 10.0——精修关键词比正文可靠，
  但仍应以标题为主信号。

## 反哺建议

检索行为已上线。后续若引入向量检索，tags 可作为候选锚点列，但不改变
「结构化 → FTS → 上下文拼装 → 模型」主链路。
